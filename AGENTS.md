## OVERVIEW

AI Story Book is a Korean-first personalized storybook product: Flutter mobile client, FastAPI/Celery backend, PostgreSQL/Redis, S3-compatible storage, and pluggable AI providers. The repository is a two-application monorepo with a generated OpenAPI snapshot and image-based production deployment.

## CONVENTIONS

- Run API commands from `apps/api`; imports use the `src.*` package root.
- Run Flutter commands from `apps/mobile`; repository-wide gates run from root.
- API identity is header-based: required `X-User-Key`, optional profile scope via `X-Profile-Id`, and idempotency via `X-Idempotency-Key`.
- Backend DTOs reject unknown input, constrain fields, and feed the OpenAPI contract. Mobile parses stable responses into typed models or strict JSON helpers.
- User-facing mobile copy belongs in all three ARB sources. English is the localization template.
- Tests replace external providers with deterministic mocks. “E2E” pytest and Flutter integration tests do not prove live provider, Celery, store, or device-plugin behavior.
- Local API configuration belongs in `apps/api/.env`; production Compose configuration belongs in `infra/.env`. Root `.env` is not the API settings source.
- Production deploys pull exact GHCR image tags. The checkout is orchestration input, not the production build artifact.

## ANTI-PATTERNS (THIS PROJECT)

- Do not hand-edit `packages/shared/schema/openapi.json`; regenerate it after route/DTO changes.
- Do not hand-edit generated Flutter localization files or platform plugin registrants.
- Do not bypass `settings` with scattered environment reads or silently fall back when production integrations are missing.
- Do not treat `/health` or `/health/live` as readiness; `/health/ready` is authoritative.
- Do not weaken user/profile ownership, parental consent, photo consent, IAP receipt verification, share-token privacy, or rate-limit boundaries.
- Do not log secrets, provider payloads containing child data, complete user keys, or share tokens.
- Do not use naïve UTC day/month boundaries for product quotas; product periods are Korea-local.
- Do not claim live/content quality from mock structural checks. Live external verification remains credentialed and manual.
- Do not edit Korean PIPA consent copy or translate it to English/Japanese without legal approval.

## UNIQUE STYLES

- Child-facing UI uses Material 3, Pretendard, centralized design tokens, and a 64 px minimum touch target.
- Generation is an observable job pipeline with persisted progress, bounded retries, partial-asset warnings, and page-level asset status.
- Backend errors use a stable envelope with correlated request IDs; access logs are structured and paths are redacted.
- OpenAPI is committed as a generated snapshot and checked against both FastAPI and the handwritten Flutter client surface.
