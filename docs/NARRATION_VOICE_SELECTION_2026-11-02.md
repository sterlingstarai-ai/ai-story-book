# 낭독 목소리 선택 — 2026-11-02 개발 기록

부모 설정에서 고른 `default`, `warm`, `deep` 선택을 페이지 오디오 API에 전달한다. OpenAI 낭독이 실제 구성된 배포에 한해 선택을 광고하며, 다른 공급자는 기본 낭독을 유지하고 선택 음성 요청은 거절한다. `warm`은 OpenAI `coral`, `deep`은 `onyx`로 고정 매핑한다. 제공자가 공식 성별을 보장하는 분류가 아니며 연령, 언어, 청취자에 따라 들리는 인상이 다를 수 있다. 가족 음성 복제는 이 기능과 별개이며 활성화하지 않는다.

기존 `audio_url`과 한국어·영어별 기본 음성은 그대로 보존한다. 선택 음성은 `(page_id, language, voice)`별 별도 테이블에 저장하고, 해당 계정·프로필 소유권 및 필수 동의를 확인한 뒤에만 반환한다. 페이지 본문이 수정되면 기존 기본 음성과 함께 선택 음성의 저장 객체를 파기 예약하고 해당 행을 제거한다. 책·계정 삭제는 기존 책 파일 prefix 파기와 페이지 외래키 연쇄 삭제를 사용한다. 선택 목소리의 첫 생성은 실제 공급자 호출 및 비용을 발생시킬 수 있으며 전역 생성 예산과 기존 이용 권한을 따른다.

같은 페이지·언어·목소리의 동시 최초 생성은 공유 Redis의 조건부 잠금으로 차단한다. 잠금 소유 토큰을 비교하여 다른 요청의 잠금을 삭제하지 않으며 Redis 장애 시 신규 생성은 중단한다. 실패·취소 후 잠금은 최대 10분 동안 남아 복구되고 요청은 다시 시도해야 한다. 공급자 작업에는 잠금보다 짧은 4분 상한을 둔다. Redis 데이터 유실·장기간 네트워크 분리나 외부 공급자의 취소 이후 처리까지 중복 결제가 절대 발생하지 않음을 보장하지는 않는다.

2026-11-02: 실제 OpenAI에 같은 가상 한국어 문장으로 `coral`과 `onyx` 각 1회 합성하여 두 파일 모두 HTTP 200과 MP3 형식을 확인했다. 이어 감정·어조 표현 지시를 보강한 최종 코드로 각 1회씩 다시 합성했다. 총 4회이고 청구액은 미확인이다. [최종 샘플](acceptance/2026-11-02-narration-expressive-samples/result.json), [초기 샘플](acceptance/2026-11-02-narration-voice-samples/result.json). 이는 실제 공급자 음성 표본이지 모든 동화에서 자연스럽거나 특정 성별로 들린다는 평가가 아니다.

백엔드 전체 검사는 **2,363 통과, 27 건너뜀**이며 대부분 모의 공급자·SQLite다. 별도 임시 PostgreSQL 16에서 이전 리비전의 기존 데이터를 보존하는 새 마이그레이션 업·다운과 두 요청의 음성 발행 경합(한 결과만 채택, 실패한 파일 파기 지시 유지)을 확인했다. 별도 임시 Redis에서는 동시 잠금 차단, 실패 시 TTL 유지, 옛 소유자가 새 잠금을 지우지 못하는 조건을 확인했다. 외부 공급자 샘플은 별도이며 운영 DB와는 연결되지 않았다.
