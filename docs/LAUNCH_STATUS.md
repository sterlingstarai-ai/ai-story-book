## 이번 개발 보완

- 계정 키 읽기 오류·유실·신규 키 저장 실패 시 새 계정으로 진행하지 않는다. 재시도 화면을 제공한다.
- Gemini 텍스트 및 사진·그림 분석 분기를 연결한다. 미지원 제공자·실제 제공자 오류를 mock 캐릭터로 반환하지 않는다.
- 환경 스키마·예시·Compose를 맞춘다. 운영 preflight에서 제공자·모델 불일치, mock, 비활성 POD 구성의 주문 노출을 검사한다.
- 저장된 미디어 주소는 DB 내부 참조로 유지한다. 소유권 확인된 읽기 응답에서만 S3 다운로드 URL을 발급하며 기본 만료 시간은 1시간이다.
- 서버의 원본 사진·PDF 이미지 읽기는 S3 인증을 사용한다. 공유 페이지는 기존 철회 가능한 토큰 프록시를 유지한다.
- 실물책 메뉴·주문 API를 같은 기능 플래그로 제어한다. 오디오 가용성을 아직 모르는 동안 버튼을 노출하지 않는다.
- 스토어 설명에서 기본 비활성인 오디오·발음·실물 주문 제공 약속을 제거한다.
- 생성 버튼 잠금을 최초 비동기 호출 전에 적용하고, 폴링 연결 실패와 실제 생성 실패를 구별해 같은 작업 상태를 다시 조회한다.
- 생성·이름 변경·삭제 후 홈·서재·상세 캐시를 함께 갱신한다. 설정을 읽지 못한 상태에서 기본값으로 덮어쓰지 않는다.
- 크레딧 차감 안에서 생성 한도를 재검사하고, Celery 작업 선점과 책·완료 상태 저장을 원자적으로 처리한다. 실패 환불 미정산 항목은 모니터가 재처리한다.
- 생성 이미지에 작업별 저장 경로를 부여해 프로세스 중단 후에도 정리할 수 있게 한다. 음성 삭제·철회도 삭제 지시를 DB에 함께 남겨 스토리지 장애 후 재시도한다.
- 신규 음성 수집을 비활성화하면서 기존 음성의 관리·철회·삭제는 유지한다. 새 음성 파일 경로에 계정 키를 넣지 않고, 과거 원문 키가 들어간 샘플 주소는 응답에 재노출하지 않는다.
- API·worker·모바일 로그에서 자격증명, 원문 아동 데이터, 서명 URL을 제거한다. Gemini 인증 키는 URL 쿼리 대신 헤더로 전송한다.
- 실제 PostgreSQL·Redis·Celery·비공개 MinIO를 사용하는 격리 검증 도구를 추가하고 CI에 연결한다. 운영 Redis는 큐·한도 카운터를 임의 퇴거하지 않도록 설정한다.

이 목록은 코드 구현을 설명하며, 운영 버킷 정책 변경이나 배포가 완료됐다는 뜻이 아니다.

## 미디어 배포 절차 — 운영자가 실행

1. 기존 버킷 데이터와 `S3_PUBLIC_URL`을 유지한다. 이 설정은 저장된 객체의 기준 주소이며 공개 읽기 허용을 뜻하지 않는다. 변경이 필요하면 기존 주소를 `S3_LEGACY_PUBLIC_URLS`에 보존한다.
2. `S3_DOWNLOAD_ENDPOINT`에 **기기에서 접근 가능한 S3 API 엔드포인트**를 설정한다. 비어 있으면 `S3_ENDPOINT`를 사용한다. Docker 내부 `minio:9000`은 실기기에서 접근할 수 없다. 서명 후 URL의 호스트를 CDN 주소로 바꾸면 서명이 깨진다.
3. 접근 키에 필요한 객체 읽기·쓰기·삭제 권한을 부여한다. 외부 공급자가 가져가는 POD PDF에는 최대 24시간 URL을 사용하므로, 향후 POD 활성화 시 공급자의 파일 수집 시점도 검증한다.
4. 버킷과 별도 CDN의 익명 읽기를 차단한다. 이미 공개 CDN으로 제공한 파일은 캐시 무효화도 확인한다. 코드 배포만으로 기존 공개 정책·캐시가 닫히지는 않는다.
5. 존재하는 시험용 객체로 `scripts/check-bucket-exposure.sh <기준 주소> <객체 키>`를 실행한다. **서명 접근 성공 + 익명 접근 실패**를 함께 확인한다. 404 응답 하나만으로 비공개 판정을 내리지 않는다.
6. 실기기에서 사진 캐릭터 생성 → 책 이미지 → PDF → 음성(활성화했을 경우) → 공유·철회 → 삭제를 확인한다. URL 만료 후 재열람도 확인한다.

클라이언트는 재열람과 만료 임박 시 새 URL을 조회한다. 오프라인에서는 이미 저장된 텍스트·기기 캐시만 이용할 수 있으며, 만료 URL로 아직 내려받지 않은 이미지를 새로 받는 것은 불가능하다. 서명 URL은 만료 전까지 접근 권한을 가지므로 로그·분석 이벤트에 넣지 않는다. 공유 철회는 공유 프록시에 즉시 적용되지만, 이미 내려받은 파일 자체를 회수하지는 않는다.

로컬 API 자격증명은 `apps/api/.env`, 운영 Compose 자격증명은 `infra/.env`에 설정한다. 키 원문은 채팅·커밋에 넣지 않는다. 모델 ID는 사용 가능한 계정의 제공자 목록과 실호출로 확인한다.

2026-09-06 로컬 `apps/api/.env`의 활성 텍스트 설정을 OpenAI/Sol로 전환했고 Gemini는 유지했다. 기존 Anthropic 전용 키는 Git에서 제외한 `apps/api/.env.anthropic.local`에 0600 권한으로 보존했다. 운영 `infra/.env`는 기존 개발용 상태이며 로컬 베타 키를 복제하지 않았다. 운영 저장소·관리자 등 출시 설정은 아직 준비되지 않았다. `scripts/final-external-preflight.sh --env-file infra/.env --json`의 마지막 판정은 **BLOCKED / launch_ready=false**다. 설정이 채워져도 이 도구는 CONFIGURED_NOT_VERIFIED까지만 판정하며 실제 출시를 자동 승인하지 않는다.

### Sonnet 5 호출 호환성 보완

실제 호출 전 [공식 Sonnet 5 마이그레이션 안내](https://platform.claude.com/docs/en/models/sonnet-5/migration-guide)와 기존 어댑터를 대조했다. 기존 코드는 기본값이 아닌 `temperature`를 전송하고 첫 번째 콘텐츠 블록을 텍스트로 가정했다. Sonnet 5에서는 각각 요청 거절과 응답 파싱 실패의 원인이 된다.

- 정확한 `claude-sonnet-5` 또는 날짜가 붙은 버전에만 샘플링 옵션을 생략하고 `thinking.type=disabled`를 명시해 이전의 비사고 모드와 토큰 예산을 유지한다. 기존 모델의 temperature 동작은 보존한다.
- 모든 Anthropic 이야기·사진·그림·텍스트 캐릭터 경로는 `type=text`인 블록을 읽는다. 거절·잘림·빈 텍스트 응답은 성공으로 저장하지 않는다.
- 새 회귀 테스트 27개를 포함한 서비스·캐릭터·Gemini·골든 구조 집중 테스트 **53개 통과**, Ruff 및 변경사항 공백 검사 통과.
- 제한된 실호출 도구 `scripts/run_ai_generation_smoke.py`는 실제 어댑터로 텍스트·이미지 각각 최대 1회만 요청한다. 이미지 저장만 로컬 파일로 대체하므로 전체 책 파이프라인·S3 검증으로 취급하지 않는다. 별도 모의 테스트 **7개 통과**.
