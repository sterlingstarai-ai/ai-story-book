# 삽화 검사와 부분 재생성

2026-09-06 후속 제공자 계정 확인, 실제 사진의 로컬 전처리와 가상 입력 실호출 결과는 [사진 실검증 기록](PHOTO_LIVE_VERIFICATION_2026-09-06.md)을 따른다. 실제 아동 사진의 외부 처리·닮음 검증과 공개 출시 승인은 별개이며 아직 완료로 표시하지 않는다.

생성된 그림을 곧바로 완성 책으로 저장하지 않는다. 본문·표지·모든 페이지 그림을 함께 검사하고, 제한된 보완 후에도 오류가 남으면 완성을 차단한다. 원본 아동 사진은 이 검토 서비스로 보내지 않는다.

2026-09-07 최종 두 참조·교정 경로는 Python3.11 전체 **1,924통과·21건너뜀·실패0**와 Ruff·과금 경로 커버리지 검사를 통과했다. 검증 도구의 이전 단일 참조 가정2건도 수정 후 전체 재검증했다. [코드 검사 증거](acceptance/2026-09-07-dual-reference-api-final/result.json). 실제8쪽 후보는 남은 결함으로 실패했으며 이 숫자가 그림 품질 통과를 뜻하지 않는다.

## 처리 순서

1. 기존 본문 안전·구조 검사를 거쳐 표지와 페이지 그림을 생성한다.
2. GPT-5.6 Sol이 전체 그림을 본문·등장인물 지시와 대조한다. 그림에 인쇄된 프롬프트, 읽을 수 있는 문자, 인물 복제, 머리·의상·특징의 교환, 중심 행동과 이야기 핵심 장치의 명확한 불일치, 위험한 묘사를 검사한다.
3. 수정 가능한 오류가 있는 그림이 본문12쪽 책은 최대3장, 그보다 짧은 책은 최대2장이면 해당 그림만 각각 한 번 새로 생성한다. 오류 코드에 대응하는 코드 내 고정 지시를 사용한다. 검토 AI가 임의로 작성한 명령을 실행하지 않는다.
4. 교체 후 표지를 포함한 전체 그림을 다시 검사한다. 모든 페이지가 통과해야 학습 자료 생성과 책 저장으로 진행한다. 보완 지시는 기존 인물 설명을 자르지 않고 제공자에게 보낼 때만 덧붙이며, 저장된 원본 지시는 유지한다.
5. 오류가 남거나, 위 조건별 교정 장수 한도를 넘거나, 위험·판정 불가·응답 누락·시간 초과가 발생하면 `IMAGE_QUALITY_FAILED`로 종료한다. 전체 책을 무한히 다시 생성하지 않는다.

단순한 자세·조명·화풍 차이나 한 장의 그림으로 확인하기 어려운 사소한 표현은 명백한 모순과 구분한다. 자동 검사는 누락·오탐 가능성이 있으므로 이 기능의 도입 자체가 무결점 또는 출시 품질 통과를 뜻하지 않는다.

`action_mismatch`는 여러 페이지에 반복되는 이야기 핵심 장치의 연속성도 포함한다. 같은 장치의 정체·인물에 대한 상대 크기·물리적 구조가 설명 없이 달라져 이야기 속 역할이나 기능이 바뀌는 명백한 경우만 결함으로 본다. 예를 들어 지상에 서 있는 허리 높이의 물통이 지면에 평평하게 놓인 점검구로 바뀌는 경우다. 본문에서 새로 소개한 별개 물체나 명시적인 변형, 조명·카메라 각도·원근·미세한 색 차이·장식·역할과 기능이 유지되는 합리적 단순화는 이 결함에 해당하지 않는다. 가상 입력 책의 육안 검토에서 AI가 놓친 실제 연속성 오류를 발견해 보강한 기준이며, 전송·응답 회귀 통과가 실검출 성공이나 품질 합격을 뜻하지 않는다. 해당 실표본의 판정은 [사진 실검증 기록](PHOTO_LIVE_VERIFICATION_2026-09-06.md)을 따른다.

물체의 종류·설치 위치·기능적 구조가 유지되는 경우 나무와 금속처럼 보이는 표면 마감·재질 차이만으로 `action_mismatch`를 부여하지 않는다. 본문이 재질을 동작이나 교훈의 핵심 조건으로 요구하거나, 독립적으로 확인되는 구조·물의 목적지·안전 모순이 있으면 계속 결함으로 검사한다. 재질만 달라진 시각적 불연속이 없다는 뜻은 아니며, 소품 디자인의 일관성 보완과 기능·행동 모순 차단을 구분한다.

## 생성 단계의 반복 소품 재발 방지

같은 이야기 핵심 소품이 장면마다 나무통·금속통처럼 달라지는 관측에 대응해, 기존 한 번의 삽화 프롬프트 생성에서 전체 본문을 먼저 읽고 소품의 재질·색·형태·상대 크기·기능 부품 배치를 하나로 정하도록 보완했다. 실제 등장하는 표지와 각 페이지에 같은 짧은 영어 설명을 반복하며, 페이지별 행동·접촉 위치·사물 상태와 함께 1200자 안에 유지한다. 본문이 정한 별개 물체나 명시적 변화는 허용하고, 인물 묘사의 중복과 장식적인 설명부터 줄인다. 별도 생성 호출·사용자 입력·DTO 필드는 추가하지 않았다.

이 지침을 적용한 후속8쪽 책에서 설명은 같아도 뚜껑 구조가 변하는3쪽을 확인했고 완성을 차단했다. 따라서 문장 지시만의 재발 방지 효과는 확인되지 않았다. 기존 책을 자동 수정하거나 이 실패를 성공으로 집계하지 않는다. 집중 검사34개와 Ruff·diff 검사를 통과했다. 새 전송 회귀2개와 기존 모의·골든 구조 검사는 지침과 전체 본문이 기존 단일 요청에 포함되고 응답 계약을 유지하는지만 확인하며, 실제 그림 품질의 증거가 아니다.

## 기존 표지를 함께 참조하는 후속 보완

첫 캐릭터 변환은 원본 참조 한 장만 사용한다. 승인된 캐릭터로 새 표지를 만든 뒤 본문에는 승인 캐릭터를 첫 이미지, 같은 작업에서 생성한 표지를 두 번째 이미지로 전달한다. 첫 참조는 얼굴·의상을 고정하고, 두 번째 참조는 해당 장면에 필요한 반복 소품의 형태·구조·화풍만 제공한다. 현재 본문·등장인물·행동이 표지의 배치보다 우선한다. 사진 없는 책은 기존처럼 표지를 인물·소품 기준으로 한 번만 전달하며 중복 이미지 전송을 제거한다.

문자·행동 같은 국소 결함의 교정은 현재 생성 페이지를 첫 참조로 써서 인물·구도·동작을 보존하고, 첫 전체 검수에서 문제가 없던 표지만 두 번째 참조로 사용한다. 인물 교환·복제는 승인 캐릭터를 첫 기준으로 유지한다. 표지 자체가 지적되면 먼저 교정해도 최종 재검수 전에는 다른 페이지로 전파하지 않는다. 기존 책의 단독 편집 첫 후보 생성은 이번에 범위를 넓히지 않았으며 이후 공통 검수·수리에는 같은 규칙을 적용한다.

OpenAI는 순서가 있는 최대2개의 `image[]` multipart, Gemini는 최대2개의 inline 이미지를 받는다. 참조를 불러오지 못하면 참조 없이 생성하지 않으며, 새 책·동시 작업·예외 종료 사이의 문맥 분리를 검사한다. 추가 캐릭터 생성이나 이미지 출력 호출은 없지만 두 번째 참조에 대한 입력 토큰 비용은 발생한다. 기존 출력·교정·검수 횟수와 시간 한도는 유지한다. 실제 품질 결과는 [후속 실호출 기록](PHOTO_LIVE_VERIFICATION_2026-09-06.md)을 따르며, 전송 회귀 통과만으로 일관성이 보장된다고 주장하지 않는다.

## 저장·비용·편집

- 새 책이 실패하면 기존 실패 처리에서 책 완성 차단, 사용 크레딧 반환, 미완성 자산 정리를 처리한다. 앱은 반환 완료 여부를 확인하지 않고 환불 완료라고 안내하지 않는다.
- 기존 페이지의 글·그림 수정, 부분 그림 수정, 연령에 맞춘 다시 쓰기도 후보를 검사한다. 통과 후에만 변경 당시의 책과 페이지 상태를 다시 확인해 원자적으로 저장한다. 검사 실패나 동시 수정 충돌이면 기존 책을 유지한다.
- 교체·실패·저장 경쟁에서 사용하지 못한 새 자산은 영속 파기 큐로 정리한다. 원본 책이 참조하는 자산을 함께 지우지 않는다.
- 새 책의 실제 이미지 HTTP 요청 한도는 `본문 쪽수 + 표지1 + 추가교정 한도`다. 추가교정 한도는 본문12쪽이면3, 그보다 짧으면2다. 일반 재시도와 품질 보완이 이 한도를 함께 사용한다. 검사 호출은 최대2회, 호출당 최대45초다. 기존 금액·작업 시간 한도를 유지하고 남은 시간이나 요청 예산이 부족하면 중단한다.
- 모바일은 ‘그림 검사 → 필요한 그림 보완 → 다시 검사’를 한국어·영어·일본어로 표시한다. 실패 시 내부 코드나 제공자 상세 메시지를 노출하지 않는다.

## 설정과 배포

실서비스는 `ILLUSTRATION_QUALITY_ENABLED=true`, 검토를 지원하는 OpenAI 모델과 키가 필요하다. 생산 환경 사전 검사와 readiness가 이를 확인하며, 검사를 끈 비테스트 실행은 생성·수정 경로에서도 거부한다. 결정적인 mock 테스트와 로컬 mock 개발에서는 플래그를 끌 수 있다.

설정 위치는 로컬 API `apps/api/.env`, 운영 Compose `infra/.env`다. 두 Compose의 API와 worker에 동일하게 전달한다. 이 변경으로 실제 운영 환경이 배포되거나 외부 저장소가 설정된 것은 아니다.

## 검증 근거

- 핵심 장치 연속성 기준의 후속 보강은 집중 회귀100개(새 전송·응답 계약2개 포함), Ruff·diff 검사로 확인했다. 전체13쪽 맥락과 좁은 결함·예외 지시가 요청에 실리고 특정 페이지의 검토 결과가 유지되는 검사이며, 실제 AI가 해당 오류를 찾아냈다는 증거는 아니다. 이전 전체 API1,848개·별도 직렬화10개 이후의 추가 검증으로 구분한다. [후속 모의 검증 기록](acceptance/2026-09-06-story-object-continuity/result.json).
- 저장된 원본5장씩 두 권에 대한 실검사: 영문 지시문이 인쇄된 책의 2쪽에서 `printed_instructions`, `readable_text`, `identity_swap`을 검출했다.
- 첫 검사에서 정상으로 판단한 물주기 장면을 불일치로 판정해, 중심 행동과 사소한 표현을 구분하는 일반 지시를 보완했다. 같은 두 권의 후속 검사에서는 정상 책의 5장 모두 통과, 오류 책의 2쪽은 동일하게 검출했다. 두 실행은 각각2회 요청·추정 $0.077660이며 초기 결과도 보존한다. 이 작은 개발 표본에서 전체 검출률을 추정하지 않는다.
- 원본·검토 결과·파일 해시·사용 토큰: Git 제외 `docs/acceptance/2026-09-06-illustration-gate/saved-review-v{1,2}/`. 저장된 그림 확장자가 `.png`여도 실제 JPEG 바이트이면 실제 형식으로 검사한다. 검증을 위해 그림을 변환하지 않는다.
- v2 검토를 기존15권75장에 적용했을 때8권을 표시하고7권은 오류를 표시하지 않았다(추정 $0.578572). 이전 육안 검토의 모든 우려를 검출한 것은 아니며, 이 수치를 민감도·정확도 또는 새 책 합격률로 사용하지 않는다.
- 실제 부분 교정 v1: 영문 지시문이 있는2쪽만 새로 생성했다. 문자는 없어졌지만 조연 외형이 바뀌어 전체 재검사가 차단했다(검토2회·그림1회, 추정 $0.217350). 기존 긴 설명의 뒷부분이 잘리는 구현 문제를 확인해, 보완 지시를 전송 시에만 추가하고 기존 설명을 온전히 유지하도록 수정했다. 이 진단은 저장소 조회·업로드를 로컬로 대체한 실제 AI/알고리즘 검증이며, DB·Celery·S3 검증은 아니다.
- 실제 새4쪽 책: 일회용 PostgreSQL·Celery·Redis·비공개 S3에서161.85초에 기술 완료했다. 검토 포함 LLM7회·그림5회, 추정 $0.938056, 임시 환경 정리 완료다. v2 검토에서는 통과했지만 독립 육안 검토에서 물의 목적지와 본문 사이 차이를 발견했다(C1=2/C4=1/S1위반0). **콘텐츠 품질 합격으로 기록하지 않는다.**
