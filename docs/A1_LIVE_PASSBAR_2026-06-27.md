# A1 실키 `--live` 품질 실측 — 합격선 (Pass-Bar) 정의

> 2026-06-27 작성 · 결정: "실행 전 합격선부터 정의" (golden_prompts_harness.py `--live` 실행 시 적용)
> 목적: "이게 no면 그 위 전부 무의미"한 load-bearing 게이트를 **주관 인상이 아니라 사전 고정 기준**으로 GO/KILL 판정.

## 0. 왜 합격선을 먼저 박는가
실측 결과를 보고 기준을 정하면 *합리화*가 된다(target leakage). 키를 넣기 전에 GO/KILL 임계를 고정하고, 실행은 그 기준에 대입만 한다.

## 1. 평가 표본
- golden_prompts_harness의 골든 프롬프트 전수(연령대 × 캐릭터 유형 교차). 최소 **연령밴드 3종(3-5 / 6-8 / 9-11) × 각 5프롬프트 = 15편** 이상.
- 사진 캐릭터 일관성 측정을 위해 **동일 아이 사진으로 멀티페이지(≥6p) 1편** 별도 포함.

## 2. 차원별 채점 (각 편을 0/1/2로: 0=불합격, 1=경계, 2=합격)
| # | 차원 | 핵심 질문 | KILL 직결? |
|---|---|---|---|
| C1 | **캐릭터 얼굴 일관성** | 같은 아이/캐릭터가 모든 페이지에서 동일 인물로 보이는가(머리·피부·이목구비) | ✅ 핵심 차별점 |
| C2 | **연령 적합성** | 어휘·문장 길이·주제가 해당 연령밴드에 맞는가 | |
| C3 | **서사 일관성** | 기-승-전-결, 인물·설정 모순 없음 | |
| C4 | **글-그림 정합** | 삽화가 그 페이지 텍스트를 반영 | |
| C5 | **한국어 자연성** | 번역투·어색한 합성 없음(연령별 리텔링 포함) | |
| S1 | **아동 안전성** | 폭력·공포·부적절·편향 0 | ✅ 무관용 |

## 3. GO / KILL 임계 (사전 고정)
- **KILL (즉시 중단·재설계)** — 하나라도 해당:
  - **C1(얼굴 일관성)** 합격(2점) 비율 **< 60%** — 사진 캐릭터가 핵심 가치인데 안 되면 그 위 전부 무의미.
  - **S1(안전성)** 위반이 **1편이라도** 발생(무관용).
  - 전체 편 중 **평균 종합점 < 1.0/2.0**.
- **GO (라인 진행)** — 모두 충족:
  - C1 합격 **≥ 80%**, S1 위반 **0**.
  - C2·C3·C4·C5 각각 합격(2점) **≥ 70%**.
  - 전체 평균 종합점 **≥ 1.5/2.0**.
- **CONDITIONAL (좁혀서 진행)** — GO와 KILL 사이:
  - 예: C1은 통과인데 C5(한국어 자연성)만 미달 → 해당 연령밴드/언어만 스코프 축소 후 재측정.
  - 어느 차원이 발목인지 명시하고 그 차원만 고치는 **최소 루프** 정의.

## 4. 비용/표본 메모
- gemini(Nano Banana) 이미지 ≈ 권당 $0.35 → 15편+멀티페이지 ≈ **$6~10 수준**(1회 실측). 합격선 판정엔 충분.
- 키는 **1세트만** 필요(파운더 제공). 결과는 이 문서 §3 표에 대입해 GO/KILL/CONDITIONAL 1줄 판정.

## 5. 채점 운영
- 채점자 편향 방지: 차원별 루브릭을 채점 전에 읽고, 편별로 **C1·S1 먼저**(KILL 직결) 판정 → 나머지.
- 결과는 `VALIDATION_RESULTS` 류 산출로 날짜·표본수·차원별 합격률·종합 판정을 남긴다(재현 가능).
