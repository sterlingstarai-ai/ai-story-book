# 디지털 서비스 완성 작업 현황

2026-09-08. 최종 범위는 **앱의 디지털 동화책·디지털 유료 결제·음성**이다. 사용자가 실물책 제작·발송 서비스를 하지 않겠다고 명시했다. 이번에 추가하던 제작·배송·실물 결제 어댑터, 화면, DB 변경과 설정은 모두 제거했다. 기존 실물 주문 메뉴·앱 경로도 제거했으며, 배포 사전 검사는 실물 주문 활성화를 차단한다. PDF 다운로드와 기기의 인쇄 기능은 배송 서비스와 별개인 기존 기능이다.

신규 결제·정기 호스팅 활성화는 보류하고, 스토어 등록·업로드·제출·공개는 사용자와 공동 최종 확인 이후 진행한다. 아래 작업은 이 경계를 유지한다.

최종 검사 결과와 실제 환경 검증의 한계는 [디지털 출시 준비 검증](DIGITAL_RELEASE_VERIFICATION_2026-09-08.md)을 따른다.

## 완료한 구현

### 디지털 구매와 구독

- Apple StoreKit 2 거래·V2 서버 알림의 서명을 공식 라이브러리와 Apple 공개 인증서로 검증한다.
- Google 인증된 Pub/Sub 알림을 검증하고 Publisher API에서 구매 상태를 재확인한다.
- 갱신·만료·취소·환불·플랜 변경을 처리하고, 검증된 신규 결제 주기 없이 월간 크레딧을 지급하지 않는다. 중복 알림·복원·반복 플랜 변경으로 중복 지급되지 않도록 했다.
- 앱 시작 시 미완료 구매를 복구하며 결제 화면과 전역 리스너가 같은 거래를 중복 처리하지 않는다.
- 고객에게는 스토어가 반환한 실제 현지화 가격을 표시한다. 등록용 초안은 베이직 월24,900원/5권, 프리미엄 월44,900원/10권이다. 종전 구성은 최근 책당 생성 원가보다 책당 매출이 낮아 수정했다. 현재 스토어에 이 가격을 등록하거나 실제 과금한 것은 아니다.

세부 계약과 계획 원가 가정: [디지털 결제 구현 기록](NATIVE_IAP_WIRING_2026-09-08.md), [등록용 상품 목록](appstore/iap-catalog.json).

### 음성

- 재생 시작 후 로딩 상태를 해제하고, 일시정지·이어듣기·완료 후 다시 듣기를 분리했다.
- 페이지·언어 변경이나 화면 종료 뒤 도착한 응답이 이전 음성을 재생하지 않도록 했다. 기존 음성 파일과 캐시를 재사용해 불필요한 재생성 요청을 줄였다.
- 원문 언어별 저장, 음성 파일 업로드의 부모 동의, 업로드 크기 제한, 다국어 인식 문장·발음 점수 처리를 보완했다.
- 오디오 파일 저장 실패·삭제와 캐시 정리를 기존 파기 작업에 연결했다. 활성화된 음성 제공자의 실제 이용 가능 관측을 readiness에 포함한다.
- 기본 AI 음성을 사용하며 가족 목소리 신규 등록·샘플 수집은 지원하지 않는다. 기존 저장 자료의 삭제와 동의 철회는 유지한다.

정확한 파일 처리 및 검사 경계: [음성 구현 기록](AUDIO_COMPLETION_2026-09-08.md).

### 운영·릴리스

- API와 worker에 새 음성·스토어 알림 설정이 동일하게 전달된다. 환경 변수 이름·형식·준비 검사도 맞췄다.
- 작업 브랜치와 수동 실행에서도 CI 검사·이미지 빌드를 수행하며, 운영 이미지 게시는 main에 제한한다.
- 실제 공개 주소·스토어 설정을 검사하는 모바일 릴리스 빌드 명령과 비밀값이 없는 설정 예시를 추가했다. 로컬 검증 빌드와 스토어용 빌드를 구분한다.
- 로컬 SDK/JDK 검색과 백업 세트 검증을 보완했다. 백업은 해시, 경로, 예상 파일과 심볼릭 링크를 확인한 뒤 복원한다.

증거와 환경 한계: [배포 준비 기록](DEPLOYMENT_WIRING_2026-09-08.md).

## 실제로 남은 외부 조건

1. **운영 호스팅**: 결제 보류가 해제된 뒤 실제 서버·DB·Storage·Redis·worker·HTTPS를 활성화한다. 이어 운영 환경에서 큐, 삭제, 서명 URL, 백업 복원과 AI 사용 가능 상태를 확인한다.
2. **스토어 연결**: 공동 최종 확인 후 실제 앱·상품·서버 알림을 등록하고 샌드박스 구매·갱신·환불·복원을 검증한다. 코드 테스트를 실제 스토어 거래 검증으로 표시하지 않는다.
3. **음성 연결**: 사용자의 개별 승인 후 기존 키의 Text-to-speech Request 권한을 저장하고 다시 확인했다. 일반 한국어 문장1회가 실제 TTS 어댑터에서 HTTP200과 5.544초 MP3로 성공했다. 배포 설정 연결·앱 전체 낭독·STT 검증은 남아 있으며, 이번에 다른 권한이나 영구 앱 설정을 변경하거나 충전하지 않았다.
4. **정책·실기기·최종 확인**: 실제 처리 계약에 맞는 공개 정책의 미확정 항목과 시행일을 확정하고, 운영 후보 빌드를 실제 iOS/Android 기기에서 사용자와 최종 확인한다. 정책 전문은 검토본이며 법률 승인·ZDR 적용을 받은 것으로 표시하지 않는다.
