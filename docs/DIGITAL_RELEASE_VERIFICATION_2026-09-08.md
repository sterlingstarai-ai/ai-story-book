# 디지털 출시 준비 검증 기록

2026-09-08. 디지털 동화책·스토어 결제·읽어주기·운영 연결 준비가 이번 작업 범위다. 실물책 제작·배송은 제공하지 않으며, 이번에 추가하던 관련 구현과 앱 진입점을 제거했다.

## 최종 구현

- 디지털 구매의 서명 검증, 스토어 갱신·만료·환불 알림 처리, 중복 지급 방지와 앱 재시작 후 미완료 구매 복구를 연결했다. 실제 표시 가격은 스토어 응답을 사용한다.
- 낭독 재생·일시정지·이어듣기·언어 전환과 캐시를 보완했다. 본문 변경, 삭제, 동의 철회 및 동시 생성에서 낡은 음성이 저장되거나 재생되는 경로를 막았다.
- 기본 AI 음성을 사용하는 제품 범위에 맞춰 가족 목소리의 신규 수집을 차단했다. 이전에 저장된 자료의 삭제와 동의 철회는 유지한다.
- 약관·개인정보처리방침의 검토본에 실제 디지털 상품과 음성 처리 범위를 반영했다. 공개 승인이나 미확정 처리 조건을 완료로 표시하지 않는다.
- API/worker 설정, 모바일 릴리스 도구, 작업 브랜치 CI와 백업 검증을 보완했다. 실제 호스팅이나 유료 기능을 활성화하는 작업과 구분한다.

구현 세부 사항: [결제](NATIVE_IAP_WIRING_2026-09-08.md), [음성](AUDIO_COMPLETION_2026-09-08.md), [운영 준비](DEPLOYMENT_WIRING_2026-09-08.md).

초기 전체 검사에서 신규 베이직 월5권과 과거 테스트의 월10권 기대가 충돌했다. 새 계약에 맞춰 첫 지급량을 수정하고, 같은 구독 재요청 시 추가 지급·차감 및 이용기간 연장이 없는지 유지·보강한 후 위 API 전체 검사를 통과했다. 미지원 가족 목소리 수집의 차단과 기존 데이터 삭제·철회도 최종 실행에 포함했다.

이번 실행에서 커버리지를 새로 측정하지 않았으므로 2026-09-07 커버리지 수치를 현재 측정값으로 재사용하지 않는다.

## 실제 환경에서 확인한 범위

- **iOS 음성 플러그인 1건 통과**: 전용 iPhone 16e 시뮬레이터에서 합성 WAV로 재생 시작, 일시정지, 위치를 보존한 재개와 정지를 확인했다. 실제 AI 음성의 발음·음질 검증은 아니다.
- **PostgreSQL/MinIO 백업·복원 통과**: 현재 스키마 `09102fac8e63`의 32개 테이블과 합성 미디어 5개를 별도 환경에 복원했다. 행·파일 해시, 제약·시퀀스, 삭제 지시·인증 폐기 기록과 비공개 접근을 확인했다. 작은 시험 데이터이며 운영 복구 시간·백업 보존·원격 보관을 보증하지 않는다.
- **Android APK 컴파일 완료, 네이티브 E2E 미완료**: 앱 설치 전 에뮬레이터의 시스템 서비스가 종료됐다. 앱 동작의 통과나 실패로 계산하지 않는다. 정상 동작하는 에뮬레이터 또는 실제 기기가 필요하다.
- **실제 TTS 일반 문장1회 통과**: 최초 `missing_scope`와 권한 저장 거절 이후, 사용자가 특정 기존 키의 Text-to-speech Request 추가를 명시 승인했다. 해당 권한을 저장·재확인한 뒤 실제 TTS 어댑터에서 HTTP200, 88,704바이트·5.544초 MP3를 받았다. 원본 아이 데이터·STT 전송은 없었고 다른 권한·영구 앱 설정 변경이나 추가 충전도 없었다. 앱 전체 낭독·STT 검증을 대신하지 않는다.

2026-09-07에 검증한 실제 12쪽 동화는 [이전 통합 검토](QA_RECONCILIATION_2026-09-07.md)의 별도 표본이다. 이번 코드 검사를 새 실제 AI 책이나 스토어 거래로 표시하지 않는다. 위 일반 문장 음성은 권한 승인 후 별도로 실행한 실제 표본이다.

## 남은 외부 조건

1. 실제 TTS 성공 키를 배포 설정에 연결하고 앱 전체 낭독 및 STT를 점검한다. 완료된 음성 생성 권한 승인을 다시 요청하지 않는다.
2. 사용자가 보류한 호스팅 결제·활성화 이후 운영 HTTPS·큐·저장소·삭제·백업 복원을 확인한다.
3. 공동 최종 앱 확인 이후 실제 스토어 앱·상품·알림을 등록하고 샌드박스 결제·갱신·환불·복원을 검증한다.
4. 실제 처리 업체·보관 조건과 시행일에 맞춰 공개 정책을 확정하고, 운영 후보를 iOS/Android 실제 기기에서 확인한다.

출시 준비 검사는 외부 조건이 비어 있으면 계속 차단한다. 실물 업체 계약·제작·배송·배송지 수집은 잔여 작업에 포함하지 않는다.

신규 상품의 등록용 가격 초안은 베이직 월24,900원/5권, 프리미엄 월44,900원/10권이다. 기존 초안이 관측한 AI 생성 원가를 감당하지 못해 조정했으며, 실제 스토어 등록이나 고객 과금은 하지 않았다. 계획 가정과 한계는 결제 구현 기록을 따른다.
