# 삭제와 동의 철회 상태 표시 — 2026-11-03

책과 캐릭터 삭제 API는 데이터 행이 삭제됐더라도 저장 파일 파기가 실패하면
`partial` 또는 `purge_retry_pending`을 반환한다. 앱은 이 응답을 성공으로
표시하던 문제를 수정했다. 책·캐릭터 목록은 삭제된 행을 반영하고, 파일 삭제가
아직 끝나지 않았다는 안내를 표시한다. 자동 재시도는 횟수 제한이 있으므로
화면에 재시도가 계속되고 있다고 보장하지 않는다. 책 삭제 시 그 책의 낭독
위치도 제거하며, 다른 책의 읽기 위치는 유지한다.

동의 API의 `purge_incomplete`는 해당 계정의 알려진 사진 동의 관련 미완료
파기 작업, 생성 중인 동화·아바타의 지연 파기 및 조회 실패를 나타낸다. 동의
저장 자체는 성공 상태로 유지한다. 앱은 철회 또는 사진 사용 해제 후 이 값이
`true`이거나 예전 서버에서 필드가 없는 경우 파일 삭제 완료가 확인되지 않았다고
안내한다. `false`는 알려진 미완료 작업이 조회되지 않았다는 뜻이지 저장소의
완전 파기를 독립적으로 증명하지는 않는다.

서버 삭제 이후에도 기존 공유 캐시의 그림·음성이 기기에 남을 수 있다. 과거
파일을 책별로 완전하게 식별할 수 없어 이를 개별 책 삭제로 모두 지웠다고
주장하지 않는다. 새 코드에서는 표지·본문·분기·편집 화면과 낭독의 신규
미디어를 `BookMediaStore`의 책별 영역에 저장하고, 기존 공유 캐시는 읽기
전용으로만 사용한다. 삭제 응답을 잃으면 요청별 영수증으로 재확인하며,
불명확한 경우 기기 데이터를 보존한다. 이 연결의 최종 통합 검증, 갑작스러운
전원 중단 내구성 및 기존 공유 캐시의 선택적 파기는 아직 완료되지 않았다.

로컬 테스트는 응답의 완료·부분 실패, 알 수 없는 동의 삭제 상태, 다른 책의
읽기 위치 보존을 확인했다. 이 변경은 운영 API나 배포 앱에 반영되지 않았으며
실제 운영 데이터 복원·외부 파기 완료 또는 공개 출시 승인을 뜻하지 않는다.
