# 창업자 관련 남은 외부 조건

2026-09-06 최신 기준은 [스토어 등록 전 공동 검토](PRE_REGISTRATION_REVIEW.md)입니다. 사용자는 개인 개발자 계정으로 준비하고 함께 앱을 최종 테스트한 뒤 등록하기로 했습니다. Apple·Play 기존 법적 정보 확인과 Apple 약관 갱신은 완료했습니다. 새 사업자 정보나 완료한 작업의 재승인을 요구하지 않으며 현재 범위는 등록 전 준비입니다.

## 보존한 자동 생성 품질 기준선 — 출시 GO 아님

새 Sol/Pro 15권 자동 생성의 판정은 **REDESIGN_REQUIRED**입니다. 기술적으로는 **15/15권 통과**했으나 본문 **60쪽·원본 그림 75장** 전수 검토에서 C1 인물 일관성 합격률이 **53.3333%**로 사전 중단선 **60% 미만**에 해당했습니다. C2는 **100%**, C3는 **86.6667%**, C4는 **53.3333%**, C5는 **100%**, 평균은 **1.773333/2**, S1 위반은 **0**입니다. 기술 성공과 텍스트 품질을 그림 품질 GO로 바꾸어 해석하지 않습니다. [최종 집계](acceptance/2026-09-06-quality-matrix-sol-v2/quality-summary.json).

이 15권의 추정 비용은 텍스트 **$2.5069**, 이미지 **$10.5995**이며 당시 시험 환경 정리도 완료했습니다. 이후 [그림 품질 검사·부분 재생성·전체 재검사](ILLUSTRATION_QUALITY_GATE.md)를 구현하고 실제 저장 그림의 교정을 검증했습니다. 새 독립 표본 전수 품질 GO는 아직 아니며 현재 내부 작업은 등록 전 디자인 보완·공동 테스트입니다. 실제 아동 정보의 외부 AI 처리 조건도 해결해야 합니다.

위 평가 시점의 누적 기술 생성 완료는 **기존 9권 + 새 15권 = 24권**입니다. 기존 9권은 합성 표본 7권, 동물 캐릭터 복구 검증용 합성 표본 4쪽 1권, 보호자 제공 이름 8쪽 1권입니다. **모델 선택용 텍스트 비교 24편은 별도**이고, 서로 다른 기준선의 표본은 합격률에 합산하지 않습니다. 실제 아동 사진 검증은 없습니다.

**텍스트 모델 선택과 로컬 적용은 완료했습니다.** [동일 과제 24편 비교](AI_MODEL_DECISION_2026-09-06.md)에서 GPT-5.6 Sol을 선택했고 로컬 `openai` / `gpt-5.6-sol` 설정으로 `check-env --mode local`을 통과했습니다. 기존 Anthropic 자격증명은 비공개 보존했고 Gemini 설정과 운영 환경은 그대로입니다. OpenAI **$10 충전**과 Google의 승인된 **₩10,000 추가 충전**도 완료했으며 자동 충전은 모두 꺼져 있습니다. 충전액은 현재 잔액을 의미하지 않으며, 완료한 연결·키 발급·결제를 다시 요청하지 않습니다.

위 행렬 평가 시점의 전체 검사는 API **1,227 passed / 14 skipped / coverage 74.21%**, Flutter **359 passed / coverage 49.66%**였습니다. 이후 그림 검사 통합 근거는 [릴리스 준비](RELEASE_PREPARATION.md)에 있으며, 분량·신고·디자인 변경의 최종 통합 검증과 실제 품질 평가는 별도로 남습니다.

이전 기록은 보존합니다. 첫 Sol/Pro 행렬의 초기 2권은 ImagePrompts 길이 초과로 실패했고 이미지 **0회**, 텍스트 추정 **$0.3801**, 나머지 **13편 미실행**으로 종료됐습니다. 이후 네이티브 스키마와 참조·등장인물 연결 보강을 적용해 새 15권을 별도로 실행했습니다. 보호자 제공 이름 8쪽 원본은 **228.23초 / LLM 6회 / 이미지 9회**, 텍스트 **$0.263580**·이미지 **$1.266672** 추정 비용으로 기술 완료됐지만 **C1=0 / C2=2 / C3=2 / C4=1 / C5=2, S1 위반 0**으로 보류됐습니다. 이 원본에서 그림을 별도 편집한 개인 읽기용 최종 PDF는 10페이지·본문 보존 검증을 완료했으나 자동 생성 품질 집계에서 제외합니다.

## 이미 처리한 결정과 작업

- 무료 제한 베타로 진행하며 새 구매·오디오·실물 주문은 끕니다.
- 본문 12쪽 기본·짧은 동화 8쪽·4쪽 체험/내부 테스트를 구현했습니다. Apple·Play 개인 계정 정보 확인과 Apple 약관 동의 갱신도 완료했습니다.
- Anthropic과 Google Gemini의 로그인·API 키·결제 연결과 실제 생성 호출은 완료했습니다. Google의 승인된 ₩10,000 추가 충전도 완료했으며 자동 충전은 꺼져 있습니다. 키 발급이나 로그인 승인을 다시 기다리고 있지 않습니다.
- OpenAI 전용 프로젝트·Restricted 키 확보와 모델 metadata HTTP 200 확인을 완료했습니다. 사용자 $10 충전 후 같은 프로젝트 결제 화면에서 충전 완료·자동 충전 꺼짐을 확인했고 실제 모델 비교와 전체 책 생성까지 진행했습니다. 초기 결제 요청은 종료됐으며 관련 추가 입력 요청은 없습니다.
- Android 업로드 서명키를 로컬에 만들고 보호 설정·서명 검증을 마쳤습니다.
- 계정 복구 구현·회귀 검사·실제 PostgreSQL 동시성 검증, PDF 렌더 보완, 격리 DB/비공개 미디어 백업 복원 리허설을 완료했습니다.
- 기존 구현 결정 기록은 [DECISIONS_NEEDED_2026-07-20.md](DECISIONS_NEEDED_2026-07-20.md)에 보존합니다. 해당 문서의 과거 선택지를 현재 미결 항목으로 다시 해석하지 않습니다.
