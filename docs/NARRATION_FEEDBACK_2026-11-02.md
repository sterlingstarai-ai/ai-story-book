# 낭독 피드백 반영 — 2026-11-02

사용자는 실기기 시험에서 페이지 번호와 장면 안내 문구가 흐름을 끊고 낭독이 느리다고 지적했다. 확인 결과 시험용 mock 동화 본문 생성기는 실제로 `페이지 N:`과 `장면 N의 이야기입니다.`를 본문에 넣으며, TTS는 본문을 그대로 읽는다. 별도 재생기는 이 문구를 삽입하지 않는다. 실기기 시험의 복원 데이터는 `text`와 한국어 `text_ko`가 서로 다른 샘플을 가리켰을 가능성이 있어, 사용자가 들은 내용이 실제 AI 생성 동화의 본문이었다고 단정할 수 없다. 오디오용 본문 선택은 `text_ko`가 있으면 이를 우선한다.

mock 동화의 번호·안내 문구를 일반 이야기 문장으로 바꾸고 새 실제 동화의 생성 지침에 이런 메타 안내를 본문에 넣지 않도록 명시했다. 사용자가 직접 쓴 본문이나 기존 동화에서 단어를 자동 삭제하지 않는다. 생성 지침만으로 실제 공급자의 출력을 항상 보장하지는 않는다.

연령별 합성 속도는 기존 3–5세 0.65배, 5–7세 0.80배, 7–9세 0.90배에서 모두 기본 1.0배로 조정했으며 자연스러운 대화 속도의 낭독을 지시했다. 이는 새로 생성하는 음성에 적용된다. 기존 저장 오디오는 URL을 그대로 재사용하므로 바뀌지 않으며, 기존과 새 음성을 구분할 합성 속도 메타데이터가 없어 일괄 재생 배속이나 삭제·재생성을 하지 않았다. 수정 후 실제 음성 청취와 선호도는 아직 검증 전이다.
