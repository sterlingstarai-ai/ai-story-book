## 소유자 요청과 후속 정리

기존 Google Cloud·스토어 로그인과 정책 승인을 다시 요청하지 않는다. 별도 계정 재개설·ZDR 재승인도 이번 작업에 포함하지 않는다.

1. **보호자 메일 발송 인증은 현재 보류.** 실제 비공개 설정·암호 파일이 없고 운영 메일 기능은 꺼져 있다. 처음에는 앱 비밀번호 연결을 요청했지만 사용자가 필요성을 물어, 앱 비밀번호 자체가 필수는 아니며 현재 SMTP 구현의 인증 방식이라고 설명했다. Google OAuth나 다른 발송 서비스도 대안이다. 지금 새 비밀번호를 만들도록 요구하지 않고, 준비했던 본인 확인 탭도 닫았다. 현재 스토어 심사를 위해 기존 로그인·2단계 인증을 반복할 필요는 없다. 보호자 이메일 기능을 공개하기 전에는 실제 발송 권한과 수신·동의 검증이 필요하다.
2. **최종 기기 확인.** 현재 iPhone은 연결된 기기가 없고 Android도 준비된 USB 기기가 없다. iPhone TestFlight 6·Android Play Alpha 5 설치와 연결 후 기존 책으로 마지막 쪽 낭독·스피커·화면을 확인한다. 새 동화·그림·낭독 합성을 요청하지 않았다.

```bash
cd /Users/jmac/Desktop/ai-story-book && ./apps/api/venv/bin/python scripts/connect_guardian_smtp.py --execute --account sterling.star.ai@gmail.com
```

위 명령은 나중에 기존 SMTP 방식을 사용할 경우의 준비 명령이며, 지금 실행을 요구하지 않는다. 성공 상태는 `SMTP_AUTH_VERIFIED`다. 자격 연결만으로 실제 발송·수신·명시적 동의가 검증되거나 운영 기능이 켜지는 것은 아니다. 필수 메일 활성화 전 발송·동의 흐름과 스토어 신고의 필수 여부를 다시 맞춘다. 사용자가 맡은 Google 테스터 모집은 추가 요청 목록에서 제외한다.
