# App Store Submission Assets

This folder tracks store submission assets and templates.

- screenshots/
  - iphone-6.7/
  - iphone-6.5/
  - ipad/
- description.ko.md
- description.en.md
- keywords.txt
- submission-checklist.md

## Usage

1. Replace screenshot placeholders with final device captures.
2. Copy description templates into App Store Connect / Google Play listing fields.
3. Update `keywords.txt` with final ASO-approved keywords.
4. Run `submission-checklist.md` before each submission build.
