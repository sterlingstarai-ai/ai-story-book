# AI 동화책 (Korean Description)

아이와 함께 만드는 맞춤형 AI 동화책.

## 주요 기능
- 아이 맞춤 동화 생성: 주제/연령/스타일에 맞춘 이야기 생성
- 읽기/듣기/인쇄: 오디오 재생, PDF 공유, 인쇄 지원
- 부모 보호 기능: 부모 동의, 연령 게이트, 화면 시간 제한
- 학습 지원: 발음 연습, 읽기 통계, 스트릭 캘린더

## 구독 및 크레딧
- 월 구독 또는 크레딧 팩으로 동화 생성 가능
- 구매 전 연령 게이트를 통해 보호자 인증 진행

## 개인정보 및 보호
- 보호자 동의 기반 수집/처리
- 앱 내 데이터 삭제 요청 지원
- 자세한 내용은 개인정보처리방침/이용약관 참고

(최종 심사 제출 전 실제 가격/정책/지원 언어를 최신값으로 교체)
