# AI 동화책 (Korean Description)

아이와 함께 만드는 맞춤형 AI 동화책입니다. 무료 베타의 새 동화 만들기는 초대된 계정에서 이용할 수 있습니다.

## 주요 기능
- 아이 맞춤 동화 생성: 주제/연령/스타일에 맞춘 이야기 생성
- 동화 읽기와 서재 보관
- 3–5세 동화의 한국어 낭독과 낭독 스타일 선택
- 부모 보호 기능: 부모 동의, 연령 게이트, 화면 시간 제한
- 읽기 활동: 읽기 통계와 스트릭 캘린더

## 무료 베타 이용
- 초대된 새 계정은 그림이 있는 첫 동화책 한 권을 무료로 만들 수 있습니다.
- 신규 구독·크레딧 구매는 제공하지 않습니다.
- 새 동화와 낭독을 만드는 횟수는 계정과 서비스 전체의 이용 한도에 따라 제한됩니다.
- 기기를 바꾸거나 앱을 다시 설치하기 전에 보호자 설정에서 복구 코드를 발급해 보관하면 기존 서재를 복구할 수 있습니다. 기기 인증과 복구 코드를 모두 잃으면 복구할 수 없습니다.
- 기존 구매가 있는 사용자의 구매 복원과 크레딧 조회는 유지합니다.
