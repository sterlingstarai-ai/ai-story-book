# 키체인 기반 가상 동화 격리 시험 — 2026-11-03

사용자가 실제 동화·그림 생성을 승인해 키체인 항목을 읽고, 새 파일 입력 경로를 통해 가상 인물과 4쪽 책을 생성하는 격리 시험을 한 번 실행했다. 글·그림 호출 상한은 각각 16회·7회로 고정하고 그림 품질 게이트를 유지했다. 실제 아동의 이름·사진·개인정보, 운영 DB·스토리지·서비스는 사용하지 않았다. 키 본문은 프로세스 인자·환경변수·Docker 설정·보고서에 넣지 않았다. 키 파일은 이 실행의 비공개 임시 디렉터리에 0600으로 만들고 사용 후 제거했다.

결과는 **실패**다. 캐릭터 생성 중 실제 OpenAI Responses 글 요청 한 번이 HTTP 401을 반환했고 앱은 `credentials_rejected` 및 `AI_PROVIDER_UNAVAILABLE`로 분류하여 502를 응답했다. 그림 요청은 없었다. 사용자가 이전에 전달한 `BOTH_MODELS_VERIFIED_IN_ISOLATION`과 다른 관측이지만, 이번 키체인 항목이 당시 검사한 키와 같은지 확인하지 못했고 제공자의 세부 오류 코드는 보존하지 않아 거절의 구체적 원인도 확정할 수 없다. HTTP 401 하나만으로 어떤 조치가 필요한지 단정하거나 실제 책의 성공·품질·운영 readiness로 해석하지 않는다.

가상 실행 소유 컨테이너·볼륨·네트워크와 임시 키 디렉터리가 남지 않은 것을 확인했다. 결과 파일은 `docs/acceptance/2026-11-03-keychain-fictional-90a3536d2de1/result.json`이며 공급자 호출 수·HTTP 상태는 같은 디렉터리의 `provider-usage.jsonl`에 기록됐다. 이 파일들은 실제 사용자 정보를 포함하지 않는 가상 시험 결과다. 실행 산출물의 일반적인 키 문자열 패턴은 발견되지 않았으나 포괄적인 비밀 부재 보증은 아니다.

이후 같은 저장값을 독립적으로 확인하려던 시도는 키체인 읽기가 시간 초과되어 공급자 호출 전에 종료했다. 추가 유료 요청은 하지 않았다. 키체인 인증 대기 또는 macOS 상태 등 시간 초과의 원인은 미확인이다.

## 키 갱신 후 재시험

사용자가 키체인 갱신 도구의 `VERIFIED` 및 `keychain_updated=true` 결과를 제공한 뒤 같은 조건의 새 격리 시험을 한 번 더 실행했다. 가상 4쪽 동화·표지와 삽화가 실제 API·Celery·PostgreSQL·Redis·MinIO를 거쳐 완성됐고 자동 그림 검수를 통과했다. 재생성 1회가 포함됐으며, 글 모델 요청 8회와 그림 모델 요청 6회는 모두 HTTP 200이었다. 본문 작업은 238.58초가 걸렸고 타 계정 미디어 접근 차단도 시험했다. 초기 격리 readiness는 제공자 관측 전 503이었으며 운영 서비스의 현재 readiness를 뜻하지 않는다.

표지와 4쪽 그림을 가상 본문과 대조했다. 인물·화풍은 대체로 일관되고 3쪽의 부채와 종이, 4쪽 책장 장면은 본문과 대체로 맞는다. 2쪽에서는 본문에 아이들이 책을 펼쳤다고 나오지만 아이들이 만지는 책들이 그림상 닫혀 있어 일치가 아쉽고, 표지와 1쪽 구도도 매우 유사하다. 같은 문단의 앞선 행동인 어른의 책 이동 장면으로 볼 여지도 있어 한 장면만으로 자동 오판 원인을 확정할 수 없다. 이 검토는 AI 보조 육안 검토이며 독립 사람 검토·다수 사례 합격·운영 품질 증거가 아니다.

위 범위에서 검수 지시에 명확히 보이는 중심 물건의 열림·닫힘 상태를 비교하되, 가려진 부분이나 텍스트에 별도로 명시된 이전 시점은 단정하지 않도록 추가했다. 교정 지시에도 이야기에서 요구하는 물건 상태를 보여주도록 추가했다. 이미지 검수·교정·파이프라인 집중 검사 120개, 기존 골든 구조 검사 8개 및 Ruff가 통과했다. **수정 후 실제 모델의 검출률과 신규 실생성 결과는 아직 측정하지 않았다.**
