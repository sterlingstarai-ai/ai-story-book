# 운영 계정 확인과 실행 구성

확인일: 2026-09-06. 로그인된 계정의 프로젝트 목록과 새 프로젝트 화면을 직접 확인했다. 다른 서비스의 프로젝트·요금제·데이터는 변경하지 않았다.

## 확인 결과

- Supabase는 Free이며 기존 다른 서비스의 활성 프로젝트 2개가 있다. 새 프로젝트 화면이 무료 프로젝트 한도 초과로 생성을 차단한다. 다른 프로젝트를 정지하거나 기존 데이터베이스를 공유해 이 제한을 피하지 않는다. 무료 한도는 조직을 추가해도 소유자 전체에 적용된다. [계정별 한도](https://supabase.com/docs/guides/platform/billing-on-supabase).
- Vercel은 Hobby이며 AI Story Book 전용 프로젝트는 없다. Hobby는 개인·비상업 용도로 제한되므로 상업 제품의 운영 안내 페이지를 이 플랜에 배포하는 것을 확정하지 않는다. [Hobby 조건](https://vercel.com/docs/plans/hobby).
- Render는 기존 로그인 세션이 없어 개발용 Google 계정으로 무료 작업공간을 준비했다. Billing에서 Hobby, 서비스0개, 카드 미등록, 미청구액 없음과 잔액$0을 확인했다. 유료 서비스는 만들지 않았다. 월 구성 승인 후에는 Render 결제수단 등록도 필요하다.
- OpenAI의 실제 아동 정보 처리 조건, 공개할 정책·지원 연락처, 공동 최종 앱 검토는 호스팅 계정과 별개의 조건이다.

## 검토 가능한 초기 운영안

현재 API·Celery·Redis 구조를 유지하고, Supabase 전용 유료 조직에 동화 프로젝트 1개만 둔다. 기존 무료 조직을 통째로 업그레이드해 다른 프로젝트까지 과금시키지 않는다. API와 워커는 Render 상주 서비스로, Redis는 영속 Key Value로 둔다. 공개 정책·지원 문서는 같은 운영 계정의 정적 사이트를 사용할 수 있어 Vercel 추가 유료 플랜이나 독립 도메인을 필수로 구매하지 않는다.

| 항목 | 초기 구성 | 기본 월 추정 |
|---|---|---:|
| Supabase | 전용 Pro 조직, 기본 프로젝트 1개 | $25 |
| API | Render 0.5 CPU / 512MB, 인스턴스 1개 | $7 |
| 생성 워커 | Render 1 CPU / 2GB, 인스턴스 1개 | $25 |
| Redis | Render Key Value 256MB, 영속 저장 | $10 |
| 공개 안내 페이지 | Render 정적 사이트 | 별도 컴퓨트 요금 없음 |
| 합계 | 초기 인스턴스 구성 | **$67/월** |

가격은 공식 페이지의 2026-09-06 표시를 확인했다. 워커 2GB는 이미지 처리와 프로세스 여유를 위한 초기 선택이며 측정된 처리 용량 보장은 아니다. 세금·환율·AI 생성비·포함량 초과 트래픽·별도 미디어 백업 비용은 합계에 포함하지 않는다. Render 기본 워크스페이스 요금과 개별 유료 컴퓨트는 별개이며 Pro 워크스페이스 업그레이드를 포함하지 않았다. 실제 활성화 직전 계산서와 제한을 다시 확인한다. [Supabase 요금](https://supabase.com/pricing), [Render 요금](https://render.com/pricing), [Render 컴퓨트 식별자](https://render.com/docs/compute-plans).

무료 Render 웹 서비스는 휴면할 수 있고 무료 Redis는 재시작 시 데이터를 잃을 수 있다. 작업 큐와 차감·제한 카운터를 사용하는 현재 제품의 운영 구성으로 이를 선택하지 않는다. [무료 서비스 제약](https://render.com/docs/free).

## 연결 전후 실행 항목

1. 외부 DB의 인증서 검증, S3 리전·경로 주소·기존 비공개 버킷 연결, 전용 외부 Compose와 사전 검증을 완료한다.
2. 추가 월 과금의 구체적인 구성 승인을 받은 뒤 전용 프로젝트·상주 서비스를 만들고 서버 비밀값을 연결한다. 외부 승인 대기 중에도 독립적인 개발·품질·릴리스 준비는 진행한다.
3. 로컬의 최신 검증 소스를 나타내는 불변 API/worker 이미지와 마이그레이션을 준비한다. 오래된 원격 이미지나 `latest`를 현재 완성본으로 배포하지 않는다.
4. Supabase Data API 비활성화, 비공개 버킷 익명 접근 차단, DB TLS, `/health/ready`, 실제 큐 작업과 서명 미디어 접근을 검증한다.
5. 외부 DB·미디어 백업과 삭제·동의 철회 재적용까지 복원 검증한다. 공개 정책·지원·삭제 경로를 승인된 실제 정보로 연결한다.
6. 공동 최종 검토 전 스토어 앱 레코드·Bundle ID·업로드·심사 제출·공개 출시는 진행하지 않는다.

이 문서는 실제 운영 연결이나 신규 결제를 완료했다는 증거가 아니다. 검사에 연 Supabase·Vercel·Render 계정 확인 탭은 확인이 끝나는 대로 닫는다.
