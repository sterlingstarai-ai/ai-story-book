# 스토어 등록 전 공동 검토

> 2026-09-06 최신 확정: 사진 → 대표 캐릭터 한 장 → 부모 최초 확인 → 이후 책에 고정 재사용. 책마다 캐릭터를 새로 생성하지 않는다. 구현·처리 조건의 정본은 [사진 캐릭터 흐름](PHOTO_CHARACTER_FLOW.md)이다. 실제 사진 품질과 제공자 승인 확인은 자동 테스트 통과와 별개다.

2026-09-06 확인 기준. **사용자와 함께 앱을 보며 최종 테스트한 뒤 등록 여부를 정합니다. 현재 범위는 등록 전 준비와 디자인 보완입니다.** 이 문서는 계정 확인 이후의 진행 기준이며, 이전 문서의 Apple 약관·사업자 정보 재요청보다 우선합니다.

앱 전체 디자인의 최신 구현·검사 범위는 [최종 디자인 검토](FINAL_DESIGN_REVIEW_2026-09-06.md)를 확인합니다. 사용자는 기존 Vercel·Supabase 계정을 보유하고 있으며, 새 프로젝트 연결은 아직 확인하지 않았습니다. [앱 전용 호스팅 구성](APP_ONLY_HOSTING_PLAN.md)은 별도 도메인 구매 없이 운영하는 방안과 필요한 서버 작업을 구분합니다.

## 제품 구현과 검증

- **본문 12쪽 기본 / 짧은 동화 8쪽 / 4쪽은 체험·내부 테스트**로 구현했습니다. 생성 화면에는 12쪽과 8쪽만 표시하며 표지는 본문 쪽수에서 제외합니다. 기존 4~12쪽 API 요청은 호환됩니다.
- 요청한 본문이나 그림 프롬프트의 쪽수가 부족하면 이미지 생성 전에 차단합니다. 4·8·12쪽 mock 생성·그림·학습 자료 연결과 작은 화면·큰 글자·3개 언어의 선택/요청 전달은 검증했습니다. 실제 12쪽 AI 생성의 내용·그림 품질·시간·비용 검증은 남아 있습니다.
- **그림 전체 검사 → 문제 쪽만 제한적으로 재생성 → 전체 재검사 → 계속 실패하면 완성 차단** 흐름은 구현했습니다. 기존 책 보존·실패 자산 정리·크레딧 반환과 실제 저장 그림의 부분 교정 근거는 [그림 품질 검사](ILLUSTRATION_QUALITY_GATE.md)에 있습니다.
- 기존 Sol/Pro 15권 전수 검토의 C1 인물 일관성과 C4 글·그림 일치 합격률은 각각 **53.3333%**였습니다. 검사 기능 구현이나 한 쪽 교정 성공이 이를 새 독립 표본 전수 GO로 바꾸지 않습니다. 공개 출시 품질 판정은 보류합니다.
- 앱 내 콘텐츠 신고 기능과 운영 대기 목록 도구를 구현했습니다. 실제 시뮬레이터에서 접수·복귀를 확인했고, 보호자 확인창 전환 오류를 수정했습니다. 공동 최종 테스트는 계속 진행합니다.
- 무료 제한 베타의 새 구매·오디오·실물 주문 비활성화는 유지합니다. 이미 완료한 AI 로그인·키 발급·충전을 다시 요청하지 않습니다.

이전 전체 코드 검사와 실제 AI/런타임 검증은 [릴리스 준비](RELEASE_PREPARATION.md)와 [그림 품질 검사](ILLUSTRATION_QUALITY_GATE.md)에 보존합니다. API1,441개·Flutter405개·iOS시뮬레이터4개 통과는 사진 캐릭터 선확정 구현 이전의 분량·신고·디자인 검사 기록입니다. 최신 통합 결과와 격리 환경·건너뜀·검증 한계는 [사진 캐릭터 흐름의 구현 검증 기록](PHOTO_CHARACTER_FLOW.md#2026-09-06-구현-검증-기록)을 기준으로 확인합니다. 공동 최종 테스트와 출시 품질 판정은 별도입니다.

- 실제 서비스 구성에 맞는 개인정보·고객지원 고지와 법률 검토. 새 사업자 등록 정보 제출을 개인 계정 준비의 선행조건으로 요구하지 않습니다.

## 앱 전용 서비스 주소 (2026-09-06 정정)

사용자는 앱으로만 서비스한다. 별도 웹앱이나 독립 도메인 구매는 필수가 아니다. 운영 API에는 공개 HTTPS 주소가 필요하고 개인정보처리방침·약관·고객지원은 외부에서 읽을 수 있는 페이지로 준비한다. 호스팅 제공 기본 주소도 사용할 수 있다. 사용자에게 도메인 구매를 필수 창업자 작업으로 요구하지 않는다.

모바일의 소유 미검증 `aistorybook.com` 고정 링크는 제거했다. 정책 주소를 `PRIVACY_POLICY_URL` / `TERMS_OF_SERVICE_URL` 빌드 설정으로 제공하며, 없는 미리보기에서는 준비 중 안내를 표시한다. 이는 공개 정책 페이지가 운영된다는 뜻이 아니며 출시 전 실제 URL을 연결·검증해야 한다. 기존 법률 문구는 변경하지 않았다.
