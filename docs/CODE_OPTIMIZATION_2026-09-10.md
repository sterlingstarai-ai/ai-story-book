# 코드 최적화 검증 — 2026-09-10

API·모바일·운영 스크립트의 정적 검사와 전체 자동 검사를 기준으로, 확인된 서재 페이지 이동 오류와 비동기 응답 경합을 수정하고 성장 통계의 반복 조회를 통합했다. 모든 코드 경로의 최적성을 입증하거나 운영 성능을 보증하는 보고서는 아니다.

## 적용한 변경

| 영역 | 확인한 문제 | 변경 |
|---|---|---|
| API 서재 | 동일 생성 시각에서 정렬과 커서 조건 불일치, 제목순 커서 미적용 | 생성 시각·제목에 ID 보조 정렬을 적용하고 커서 조건을 일치시킴 |
| API 서재 | 요약 목록과 커서 조회에서 Book 전체 필드 로딩 | 목록은 응답에 필요한 9개 필드만 로딩, 커서는 ID·생성 시각·제목만 조회. 프로필 검증은 ID만 조회 |
| API 서재 | 커서 조회가 현재 프로필·필터 범위를 반영하지 않음 | 목록과 같은 소유자·프로필·스타일·연령 조건으로 커서 조회 |
| 성장 리포트 | 읽기 3회·독해 퀴즈 2회 조회 | 조건부 COUNT로 읽기 1회·독해 퀴즈 1회로 통합. 리포트 전체 조회 수를 2회로 줄였다는 뜻은 아님 |
| 또래 비교 | 집계에 총 5회 조회 | 읽기 통계 통합, 모든 퀴즈의 활성 여부와 독해 정확도를 함께 집계하여 총 3회로 축소 |
| 모바일 서재 | 이전 페이지·필터 요청이 새 결과를 덮어쓸 수 있음 | 요청 버전으로 이전 성공·실패 응답을 무시하고, dispose 이후 응답도 차단 |
| 모바일 서재 | 처리 중인 필터를 되돌리면 최신 선택이 생략될 수 있음 | 요청 중인 필터 상태를 기준으로 다음 선택 처리 |
| 모바일 서재 | 페이지 사이 중복 책과 마지막 커서 잔존 | ID 집합으로 중복 제외, 마지막 페이지의 커서를 명시적으로 제거 |
| 운영 스크립트 | 미사용 import·불필요한 f-string 18건 | 실행 의미와 출력 문구를 유지하며 정리 |

학습 통계의 사용자·프로필 범위, 어휘와 독해의 분리, 활동 없음의 `None` 처리와 점수 계산은 유지한다. API 응답 필드와 DB 스키마는 변경하지 않았다.

## 회귀와 측정

- 서재 새 회귀 3개는 변경 전 최신순·오래된순·제목순 모두 실패했으며 변경 후 통과했다. 동일 시각·동일 제목의 책을 세 페이지에 걸쳐 중복·누락 없이 조회하고 타 사용자 책을 제외한다.
- 또래 집계 새 회귀는 실제 세 번의 DB 실행, 읽기 전용·어휘 전용·활동 없음의 지표와 활성 사용자 구분을 확인한다. 기존 다중 프로필·빈 리포트 검사도 유지한다.
- 모바일 새 회귀 4개는 새로고침과 이전 페이지 요청의 역순 성공·실패, 필터 되돌리기, 중복 페이지 요청·책 병합, dispose 후 응답을 확인한다.
- Python 소스 126개 구문 검사, 셸 스크립트 13개 구문 검사 통과. API·테스트·루트 스크립트 Ruff와 CI 환경 계약 통과.
- 변경한 부하 도구 두 개의 `--help` 정상 종료. 품질 도구의 mock CI 검사 통과(95.56%, 기준 85%). 이 mock 점수는 실제 삽화 품질이 아니다.

별도 메모리 SQLite에서 합성 사용자 100명, 읽기 5,000건, 퀴즈 10,000건을 만들고 이전 HEAD의 서비스와 변경 후 서비스를 비교했다. 응답은 동일했다. 준비 실행 후 전후 측정 순서를 번갈아 20회 실행한 중앙값이다.

| 경로 | 이전 중앙값 | 변경 후 중앙값 |
|---|---:|---:|
| 또래 집계 `_bulk_metrics` | 8.844ms | 7.102ms |
| 성장 리포트 `get_growth_report` | 3.698ms | 3.026ms |

로컬 SQLite·합성 데이터의 단일 측정이며 운영 PostgreSQL, 네트워크 지연, 처리량 또는 실사용자의 체감 개선율로 일반화하지 않는다. 원본 측정 스크립트와 JSON은 Git 제외 경로 `docs/acceptance/2026-09-10-code-optimization/`에 보관한다.

## 검증 경계

외부 AI 호출·과금·운영 배포·스토어 작업은 수행하지 않았다. 생성 이미지 동시 실행 제한, 제공자 재시도·타임아웃, 개인정보·동의·크레딧 경계는 변경하지 않았다. 전체 자동 검사가 통과해도 실제 AI 삽화 품질이나 공개 출시 승인을 뜻하지 않는다. 운영 지연·CPU·메모리의 추가 최적화 판단에는 실제 운영 환경의 프로파일이 필요하다.
