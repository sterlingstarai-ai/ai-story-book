# 운영·릴리스 배선 보완

2026-09-08. 신규 결제·서비스 활성화·스토어 등록·업로드 없이 가능한 코드와 로컬 검증을 진행했다. 사용자 확정 범위는 디지털 앱·유료 결제·음성이며 실물 제작·배송 서비스는 제외했다.

## 완료한 변경

- Apple 서명 알림과 Google Pub/Sub 알림의 새 설정을 로컬/운영/외부 Compose와 Render API·worker 양쪽에 연결했다. 실제 비밀값은 템플릿에 포함하지 않는다.
- 기존 `PRINTFUL_SYNC_VARIANT_ID` 빈 문자열이 `Optional[int]` 파싱을 실패시키던 배포 부팅 결함을 수정했다. 기능이 꺼져 있으면 0으로 부팅하고, 실물 주문 플래그는 계속 꺼져 있고 공개 배포 검사에서도 활성화를 차단한다. Apple 앱 ID도 같은 방식으로 비활성 기본값을 처리한다.
- 유료 기능 사전 검사에 Apple 앱 ID·실운영 환경과 Google 인증된 push 대상 조건을 추가했다. 구성 검사가 실제 스토어 영수증·결제 성공을 대신하지 않는다. `--check-planned-features`는 디지털 결제와 음성만 검사하며 실물 주문 활성화를 요구하지 않는다.
- `codex/**` push와 수동 CI 실행에서도 코드 검사와 API/worker 이미지 빌드·스캔을 수행하도록 했다. 레지스트리 인증·게시·배포는 기존 main 경로에만 남는다. 이 문서 작성 시 변경된 원격 CI는 아직 실행하지 않았다.
- `mobile-toolchain.sh`가 기존 Android SDK와 Android Studio JDK를 스크립트 프로세스에서 탐색한다. SDK 부재라는 이전 판단은 PATH 누락 때문이었다. 전역 셸·Flutter 설정, SDK 설치, 라이선스 상태를 바꾸지 않았다.
- 로컬 iOS 호환성 빌드에 debug/no-codesign을 명시했다. `build_mobile_release.py`는 별도 public JSON만 받고 공개 API/정책 URL과 Android 서명 파일을 검증하며 `--execute`가 있어야 로컬 릴리스 빌드를 실행한다. 서버 env/비밀값을 모바일에 넣거나 자동 업로드하지 않는다.
- `verify_backup_set.py`는 명시한 로컬 백업 세트의 덤프/미디어 SHA-256·크기와 누락·추가·중복·경로 이탈·심볼릭 링크를 검사한다. 최신 삭제/인증 폐기 재적용과 복구 완료를 주장하지 않는다.

## 이번 검증

- 외부 사전 검사·Render·배포 구성·CI·모바일 릴리스 도구 회귀를 보강했다. 현재 디지털 서비스 범위에 맞춘 사전 검사 4가지 직접 실행과 백업 파일의 정상·손상·누락·추가·중복·경로·링크 차단 8가지 직접 실행을 통과했고, 정식 회귀에도 반영했다. 전체 테스트 수는 최종 통합 실행 결과를 따른다.
- 새 기능 설정의 API/worker 전달을 네 가지 배포 구성에서 확인했다. 환경 계약 검사, 수정한 Python 정적 검사와 셸 구문 검사 통과.
- Android SDK 36.1, emulator 36.3.10, Android Studio JDK 21을 확인했고 APK는 실제 컴파일했다. **Android 네이티브 E2E는 통과하지 못했다.** 앱 설치 전에 에뮬레이터의 `system_server`가 종료되어 package/activity 서비스가 사라졌다. Hypervisor 지원 조회는 가능으로 나오지만 실행 시 HVF 비활성 경고와 소프트웨어 실행으로 이어졌다. 기존 AVD 읽기 전용, 새 임시 AVD, 그래픽/가속 옵션, 일반 창 실행에서도 해결되지 않았다. 앱이 실행되기 전 실패이며 상품 기능 실패율로 환산하지 않는다.
- 최종 스키마 **09102fac8e63**를 실제 PostgreSQL에 마이그레이션하고 32개 public 테이블과 비공개 오브젝트 5개의 백업·복원을 검증했다. 행·미디어 체크섬, sequence/FK/고유 제약, 삭제 지시·폐기 계정·복구키 회전 상태, 익명 접근 차단·서명 다운로드가 모두 통과했다. 전용 컨테이너 4개를 정리했다. Docker 내부 health와 호스트 포트 준비가 다른 경우를 발견하여 읽기 전용 SELECT 1 대기를 추가한 뒤 재검증했다. 작은 합성 데이터의 검사이며 운영 RTO/RPO를 증명하지 않는다.
- 테스트 앱은 모의 API와 합성 데이터 대상이었다. 실제 사진·AI 생성·스토어 구매·주문은 이 검사의 대상이 아니다. 전용 에뮬레이터·창과 임시 AVD를 정리했고 기존 사용자 AVD를 수정하지 않았다.

비공개 로컬 증거: `docs/acceptance/2026-09-08-android-native/`, `docs/acceptance/2026-09-08-backup-restore-verified/`.

## 실제 연결 시 필요한 외부 조건

운영 서버/DB/Storage 계정 결제와 설정, 공개 정책/지원 URL, 스토어 상품/계약과 앱 ID·Pub/Sub push 자격 설정, 승인된 암호화 백업 장소는 실제 계정에서 채워야 한다. 외부 설정 후 동일 이미지·실제 저장소·공급자·기기에서 다시 검증한다. 페어링된 iPhone 15는 현재 unavailable이고, Android는 실제 기기 또는 정상 가속 에뮬레이터가 필요하다.
