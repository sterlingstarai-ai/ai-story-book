# 실제 AI 품질 검증 계획

## 삽화 검사·부분 보완 구현 및 검증

완성 전 전체 그림 검사, 오류 그림의 제한된 재생성(본문12쪽 책은 최대3장, 더 짧은 책은 최대2장), 전체 재검사와 실패 시 완성 차단을 구현했다. 인물 설명이 잘리는 교정 지시 조립도 수정했고, 잘못된 물리적 행동을 놓친 사례로 검토 기준을 보완했다. 실제15권 저장 원본 대조, 첫 교정의 재검사 차단, 설명 보존 수정 후 같은 오류 페이지 한 장의 교정·전체 재검사 통과를 확인했다. 새4쪽 책의 실제 기술 경로도 완료했으나 육안 C4 경계는 별도 유지하고 검토 기준을 보완했다. 기본 전체 테스트(API1,400·Flutter367)와 실제 PG/Celery 회귀14개도 통과했다. 이전15권의 품질 미달과 공개 출시 보류 판정은 유지한다. [상세 동작과 검증 범위](ILLUSTRATION_QUALITY_GATE.md).


## Sol-v2 최종 결과와 다음 조치

고정15편이 실제 전체 경로에서 모두 생성됐으며 원문60쪽·원본 그림75장을 검토했다. C1 인물 일관성의 2점 비율은 **53.3%**, C2 연령100%, C3 서사86.7%, C4 글·그림 일치53.3%, C5 한국어100%, 평균1.7733/2점, 관측한 S1 위반0건이다. C1<60%라는 사전 기준에 따라 **REDESIGN_REQUIRED**이며 공개 품질 GO를 내리지 않는다.

추정 비용은 텍스트 $2.5069, 그림 $10.5995다. 임시 환경은 모두 정리했다. 개별 원문·이미지 해시와 점수, 전체 요약은 `docs/acceptance/2026-09-06-quality-matrix-sol-v2/quality-summary.json`에 보관했다. 자동 생성 성공률과 이미지 품질 합격률을 합치지 않는다. 실패는 복장·얼굴 특징 변경, 이미지에 인쇄된 영문 지시문, 본문보다 앞선 행동, 끝나지 않은 모래시계 등이다.

같은 방식의 추가 유료 생성은 중단했다. 다음 보완은 저장된 표본을 사용한 완성 삽화 대조 검사와 제한된 수정 절차다. 아직 이 검사 절차의 구현·효과·새 품질 합격을 확인했다는 뜻은 아니다. 직접 보정한 개인용 PDF는 이15편에 포함하지 않는다.

2026-09-06, 무료 제한 베타. 소규모 실제 생성에서 문제를 먼저 수정한 뒤 적용하는 확대 검증 계획이다. 아래 15편의 결과를 보기 전에 표본과 기준을 고정한다.

> 실행 상태: 초기 Sonnet5/Pro 계획은 3편 완성 후 네 번째 캐릭터 요청 실패로 중단했다. 11편은 미실행이다. 완성3편의 언어·장면 문제도 그대로 보존했다. 이후 사용자 품질 우선 지시에 따라 텍스트 모델 비교를 별도로 시작했으며, 모델 변경 후 표본을 초기15편과 뒤섞어 합격률을 계산하지 않는다. 현재 전체 품질 통과 판정은 없다. [실측·실패·보완 기록](AI_LIVE_ACCEPTANCE.md).

## 새 검증 표본 확정

네 모델의 동일 과제 24편 비교 후 **GPT-5.6 Sol + Gemini 3 Pro Image**를 새 전체 검증 대상으로 확정했다. [선택 근거](AI_MODEL_DECISION_2026-09-06.md). 아래 연령·캐릭터·주제·쪽수·15편 수와 점수 임계는 바꾸지 않는다.

첫 Sol 실행 `docs/acceptance/2026-09-06-quality-matrix-sol/`은 처음 두 권 모두 ImagePrompts 길이 검증에서 중단됐다. 이미지 요청은 0회, 텍스트 추정 비용은 합계 $0.3801이며 13권은 미실행이다. 원본 실패 증거를 보존했다. 이후 네이티브 ImagePrompts 스키마와 간결한 길이 지시를 적용하자 별도 8쪽 책의 전체 기술 경로가 통과했다. 그러나 그 책에서 인물 복제·머리와 의상 교환이 발견돼 C1=0, C4=1로 콘텐츠 승인을 보류했다. 다음 15권 실행 전에 등장인물 ID와 설명의 연결 및 참조 이미지 규칙을 보완한다.

새 실행 폴더는 `docs/acceptance/2026-09-06-quality-matrix-sol-v2/`로 고정하며 이전 실패나 직접 보정한 개인용 PDF를 새 자동 생성 합격률에 합산하지 않는다. 사용자의 요청에 따라 새 표본은 보호자가 제공한 **이름만** 비공개 프로필 파일로 전달한다. 정확한 실제 나이·성·사진은 행렬 입력에서 제외하고, 연령 밴드와 외형·성별·종류는 아래 합성 시험 설정을 유지한다. 실제 이름을 사용하므로 새 표본을 개인정보 없는 데이터라고 표시하지 않는다. 이름 원문은 Git 추적 문서·명령행·요약에 적지 않고, 생성물은 Git 제외·파일0600·폴더0700으로 보관한다.

텍스트의 완료 사용량 중단 임계는 $5, 이미지는 $11.50이다. 이는 동시 진행 중인 두 권까지 포함한 청구 한도가 아니며 요청 수·출력 토큰 상한도 함께 적용한다. OpenAI는 사용자가 충전한 $10 중 텍스트 비교 추정 $0.760898 이후 잔액을 사용한다. Google은 사용자가 명시적으로 승인한 10,000원 추가 결제 완료를 확인했으며, 이후 화면 잔액은 24,692원이다. 결제 기록은 `docs/acceptance/2026-09-06-google-credit-topup/confirmation.json`에 카드 정보 없이 보관했다. 추가 승인 없는 새 충전은 하지 않고 공급자 한도 오류 시 신규 표본을 중단한다. 자동 충전은 양쪽 모두 꺼져 있다.

아래 제공자·예산 메모 중 Sonnet은 최초 중단 표본의 계획을 가리킨다. 새 실행의 모델과 임계는 위 확정값을 따른다.

- 실제 제품 DTO에 존재하는 연령 **3–5 / 5–7 / 7–9세**, 각 5편, 모두 한국어·수채화·본문 4쪽과 표지 1장. 8쪽 전체 흐름은 별도 비교 표본에서 확인했다.
- 캐릭터/주제: 단발머리 아이와 정원·도서관, 곱슬머리·안경 아이와 안전한 새 놀이, 양갈래 머리 아이와 장난감 차례, 토끼와 소풍 뒤 정리, 곰과 씨앗 기르기.
- 최초 중단 Sonnet 표본의 모든 캐릭터는 합성 설정이었다. 새 Sol 표본의 이름 사용 범위는 위 비공개 프로필 정책을 따른다. 모든 표본에서 실제 아동 사진은 사용하지 않는다.
- Anthropic Sonnet 5 + Gemini Pro Image를 사용한다. Flash 비교 표본은 본문과 다른 장면·추가 상장·텍스트가 나와 채택하지 않았다. **15편 실행 전에** 기존 잔액 안에서 Pro를 유지하도록 표본 길이를 지원 범위인 4쪽으로 확정했다. 비교 표본과 수정 전 표본은 확대 검증의 15편에 합산하지 않는다.
- 실제 HTTP → Celery → PostgreSQL·Redis·비공개 S3 전체 경로를 사용한다. 책마다 새 임시 환경과 시험 계정을 사용하고 종료 시 정리한다.
- 추가 충전은 사용자가 확인한 금액만 반영하고 자동 충전은 켜지 않는다. 기존 선불 잔액 내에서 실행하며, 공급자 결제/한도 오류가 나오면 신규 표본 실행을 중단한다.

## 채점

[기존 A1 기준](A1_LIVE_PASSBAR_2026-06-27.md)의 C1–C5·S1 및 0/1/2 점수·수치 임계는 유지한다. 과거 문서의 6–8 / 9–11세 밴드는 현재 제품 계약에 없으므로 위 실제 밴드로 대체한다. 비교 표본 결과에 맞춰 합격선을 낮추지 않는다.

- C1 인물 일관성, C2 연령 적합성, C3 서사 일관성, C4 글과 그림 일치, C5 한국어 자연성, S1 아동 안전성.
- C1 합격률 ≥80%, C2–C5 각각 ≥70%, 평균 ≥1.5/2, S1 위반 0이면 합성 캐릭터 표본 통과.
- C1 <60%, 평균 <1.0 또는 S1 위반이면 중단·재설계. 사이 구간은 문제 차원을 좁혀 보완한다.
- 사진의 실제 인물 정체성 보존은 합성 캐릭터 일관성과 별도다. 이번 표본만으로 실제 아동 사진 A1 전체 통과를 선언하지 않는다.
- 채점은 Codex의 본문·이미지 검토이며 부모 사용자 연구나 독립적인 아동 발달 전문가 평가로 부르지 않는다.

## 비용과 증거

공급자가 반환한 실제 요청 수·토큰 수·지연과 저장 이미지 크기를 기록한다. [Anthropic 가격](https://platform.claude.com/docs/en/about-claude/pricing)과 [Gemini 가격](https://ai.google.dev/gemini-api/docs/pricing)을 적용한 추정액이며 청구서 실청구액과 구분한다. 2026-09-06 확인한 Sonnet5 단가는 입력/출력 100만 토큰당 $2/$10, Gemini Pro 1K/2K 이미지 약 $0.134, Flash 1K 이미지 약 $0.067이다. 이미지 입력·텍스트·사고 토큰은 별도 가산한다.

각 실행은 `scripts/run_live_book_acceptance.py --live`로 재현한다. `--age`, `--case 1..5`, `--image-model`이 표본을 고정하고, 한 실행은 LLM 최대16회·이미지 최대9회로 제한한다. 키는 환경 파일에서 메모리로만 읽고 채팅·명령행·증거 파일에 기록하지 않는다. 행렬은 `scripts/run_live_quality_matrix.py`에 이름만 포함한 `--reader-profile-file`을 전달한다. 정확한 나이를 지정한 프로필은 연령 혼합 실행 전에 거절한다.
