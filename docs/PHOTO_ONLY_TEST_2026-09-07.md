# 사진만 전송한 동화풍 캐릭터 검증 — 2026-09-07

사용자가 ZDR 승인 확인 전 테스트를 명시적으로 요청하고 법률 확인은 직접 진행하겠다고 했다. 그 요청으로 실제 보호자 제공 사진 한 장을 이용한 격리 테스트를 실행했다. 이를 OpenAI의 ZDR 승인이나 법률 해석 확정으로 기록하지 않는다.

## 확인한 결과

- 실제 사진 → 동화풍 캐릭터 생성 1회와 생성 그림 자동 검수 1회가 모두 HTTP 200으로 완료됐다. 검수 결과는 `issues=[]`다.
- 결과는 768×1024 PNG다. 직접 원본과 비교하여 동화풍, 한 인물, 머리·복장 대응, 문자·로고 및 눈에 띄는 신체 오류 부재를 확인했다. 일반적인 닮음 합격률이나 부모의 화면상 승인으로 확대하지 않는다.
- 원본 참조는 한 장이며 EXIF/XMP/GPS 등 메타데이터를 제거했다. 요청에는 사진, 일반적인 외형·복장 설명, 그림 지시와 모델 실행 필드가 포함됐다. 고객 입력 이름·정확한 나이·생일·연락처·프로필 ID는 보내지 않았다. 검수 요청에는 생성된 그림만 들어갔다.
- 기존 제품의 그림 생성 어댑터·캐릭터 지시·검수 함수를 사용했다. 사전 사진 분석 대신 직접 관찰한 외형 설명을 사용했으며, 저장소는 격리된 로컬 저장으로 대체했다. 따라서 실제 서비스 전체 E2E나 새 동화 한 권의 완성 결과가 아니다.
- 이미지 요청과 검수 요청은 각각 최대 1회로 제한했고 재시도하지 않았다. usage 기반 비용 추정은 **$0.050712**이며 실제 청구서·현재 잔액은 아니다. 추가 충전은 없었다.
- 결과 캐릭터는 비공개로 보존했으며 다음 개인 검증에서 같은 그림을 재사용한다. 이번에는 책을 새로 만들지 않았다.

## 설정과 상담

ZDR 및 제공자 처리 조건 검증 값은 모두 `false`로 보존했다. 사진 처리 활성화는 해당 테스트 프로세스에만 적용했으며 앱·운영 `.env`와 공개 서비스는 변경하지 않았다. 기존 전체 수락 테스트의 제공자 확인 게이트를 통과했다고 주장하지 않는다.

OpenAI의 기존 지원 대화에 사용자가 요청한 후속 문의를 전송하고 `You said` 표시를 확인했다. 문의는 사진 단독 전송을 개인정보로 보는지, 보호자 동의하의 동화풍 변환을 일반 유료 API에서 ZDR 없이 할 수 있는지, 원본과 생성 그림에 각각 어떤 조건이 적용되는지 묻는다. “개인정보가 아닐 수 있다”는 창업자의 견해로 전달했으며 확정된 법률로 단정하지 않았다. 앱 전체에는 이름·연령대 입력이 있으므로 사진 단독이라는 범위는 이미지 변환 요청으로 한정했다. 이 후속 문의에 실사진·개인 식별자·API 키는 첨부하지 않았다. 실질 회신·담당자 접수·ZDR 승인은 아직 확인되지 않았다.

공동 최종 앱 검토 전 스토어 등록·업로드·제출·출시는 진행하지 않는다. 새 자동 책 전체의 삽화 품질 및 실서비스 전체 검증은 별도로 남아 있다.
