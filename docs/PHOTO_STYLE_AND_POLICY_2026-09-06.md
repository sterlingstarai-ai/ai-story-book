# 사진의 동화풍 변환과 검수 실패 재조사

확인일: 2026-09-06. 공개 공식 문서 조사와 가상 인물의 제한된 실호출을 수행했다. 실제 아동 사진 전송, 외부 문의, 계정 데이터 설정 변경, 신규 동화책 전체 생성은 하지 않았다.

## 공식 규칙의 구분

- **실사 합성 전체가 금지된 것은 아니다.** OpenAI Usage Policies는 동의 없는 실사 초상 사용으로 진위를 혼동시키는 경우와 아동에게 해를 끼치는 내용 등을 제한한다. 평범한 사진을 동화풍으로 바꾸는 행위 자체의 일괄 금지는 확인되지 않았다. [Usage Policies](https://openai.com/policies/usage-policies/), [Image generation](https://developers.openai.com/api/docs/guides/image-generation).
- **그림체와 아동 개인정보 처리는 별개다.** Under-18 API guidance는 13세 미만 또는 해당 디지털 동의 연령의 아동 개인정보 처리 전에 API ZDR 구현을 안내한다. 부모가 조작하거나 동의했거나 출력이 수채화라는 이유의 면제는 명시하지 않는다. 현재 사진 업로드 흐름에도 이 조건을 적용한다는 것은 문구에 근거한 해석이며, 법률상 모든 사진 변환이 금지된다는 뜻이 아니다. [Under-18 guidance](https://developers.openai.com/api/docs/guides/safety-checks/under-18-api-guidance).
- **ZDR은 사전 승인 후 적용하는 계정 기능이다.** GPT Image 2 및 이미지 편집의 ZDR 호환, 학습 미사용, `store=false`는 해당 프로젝트의 ZDR 적용 증명이 아니다. 승인된 고객의 조직·프로젝트 설정 절차가 공식 문서에 있다. 특정 계정의 자격이나 부모 전용 서비스 면제는 공개 문서로 확정할 수 없다. [Data controls](https://developers.openai.com/api/docs/guides/your-data).
- 스타일 변환만으로 익명정보가 된다고 단정하지 않는다. 원본 사진을 외부 API에 보내 변환하면 그림이 완성되기 전에 사진 처리가 이미 일어난다. 입력 권한·보호자 동의 의무도 별개다. [Services Agreement](https://openai.com/policies/services-agreement/).

## 동화풍 변환 보완

기존 최초 캐릭터 변환에도 책 생성용 참조 지시가 적용됐다. 이 지시는 승인된 캐릭터의 스타일·외형을 고정하기 위한 것이지만 원본 사진에도 동일하게 적용되어, 사진의 표현을 보존하라는 지시와 동화풍 변환 지시가 충돌했다. 별도 캐릭터 지시도 매체 이름 정도였고, 뒤쪽 지시를 1,200자에서 잘라낼 수 있었다. 캐릭터 검수에는 사진처럼 보이는 결과의 반려 기준이 없었다.

`build_avatar_prompt`는 외모·나이·기본 복장을 온전히 유지하면서 단순화한 얼굴·매체별 그림 표현·사진 질감 제외를 명시한다. 신뢰된 `portrait_conversion_scope()`는 첫 사진/그림 변환에서만 사용하며 OpenAI와 Gemini에 적용한다. 이후 승인 캐릭터→책 생성의 고정 참조 규칙은 유지한다. 기존 승인 캐릭터를 자동 재생성하지 않는다.

캐릭터 검수에 `photographic_rendering`을 추가했다. 사진에 수채화 질감만 얹거나 사진 얼굴을 그림 몸에 붙인 경우도 포함한다. 검증된 문제 enum만 기록하여 개인정보·응답 원문·예외 문자열 없이 반려 이유를 확인한다.

가상 사진 한 장에 실제 제품 프롬프트·어댑터를 적용하는 제한 검증을 수행했다. 외부 이미지 요청 1회, 캐릭터 검수 3회였다. 원래 가상 실사 사진과 이전 대표 캐릭터는 모두 `photographic_rendering`으로 반려됐고 새 그림은 통과했다. 육안으로도 그림체, 머리·의상 색의 유지, 눈에 띄는 문자·복제 인물 부재를 확인했다. 저장소는 로컬 대역이므로 전체 서비스 E2E나 실제 아동의 닮음 증거가 아니다.

자동 검사: 캐릭터 생명주기·제공자·골든 구조 69개, 최종 제공자/진단 34개, 이미지 저장/Gemini 39개 통과. 중복이 있으므로 합산하지 않는다. Ruff 및 diff 검사도 통과했다.

## 앞선 책의 검수 실패

앞선 v4 책은 이미지 14회가 모두 HTTP 200이었다. 최종 검수 응답 후 앱이 실패로 종료한 것이며, 실사 이미지 생성 API가 일괄 차단했다는 근거는 없다. 기록으로 예산·작업 시간 초과와 부분 수정 프롬프트 오류 가능성을 배제했지만, 당시의 검수 응답과 임시 책 그림을 보존하지 않아 정확한 회차 원인을 복원할 수 없다. 새 스타일 검수의 반려 결과를 당시 검수 사유로 소급하지 않는다.

저장된 정상 응답을 실제 검수 처리 경로에 재생하고, 오류 3쪽·불확실 판정·제공자 거절을 각각 주입했다. 정상 결과는 그대로 반환되고 세 실패는 각각 수정 한도 초과·차단성 판정·제공자 거절 사유를 기록했다. 4개 재현은 외부 호출·유료 생성·DB 접근 없이 수행했으며 당시 v4 원인 확정이 아니다. 현재는 이 사유들을 구분해 기록하지만 이전 기록에 없던 증거를 만들어낼 수는 없다.

비공개 근거: `docs/acceptance/2026-09-06-photo-live/storybook-style-probe/` 및 `failure-replay/`. 새 12쪽 책, 읽기용 PDF, 공개 출시 승인은 여전히 미완료다. 실제 아동 사진은 제공자 처리 조건과 프로젝트 적용을 확인한 후 검증한다.
