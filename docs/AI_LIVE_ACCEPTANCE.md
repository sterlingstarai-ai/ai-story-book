## 최신 고정15편 결과

`2026-09-06-quality-matrix-sol-v2/`의 15권은 실제 전체 기술 경로를 모두 통과했고 임시 환경도 정리했다. 원문60쪽·원본75장을 검토한 합격률은 C1=53.3%, C2=100%, C3=86.7%, C4=53.3%, C5=100%이며 평균1.7733/2점, 관측 S1 위반0건이다. 사전 기준 C1<60%에 따라 **REDESIGN_REQUIRED**다. 생성 성공을 이미지 품질 합격으로 표시하지 않는다.

실측 토큰 기준 추정 비용은 텍스트 $2.5069와 이미지 $10.5995다. 세금·환율·최종 청구 조정은 별도다. 주요 결함은 인물별 옷·얼굴 특징의 변화, 긴 영문 지시문의 이미지 내 인쇄, 본문과 다른 행동 대상·진행 시점이다. 같은 방식의 추가 유료 생성은 멈췄고, 저장된 표본으로 완성 삽화 대조 검사와 제한된 수정 절차를 추가했다. 검사 효과의 개발 검증은 위 최신 기록을 따르며 새 출시 품질 통과 판정은 내리지 않았다.

원본 자동 생성에서 문제가 발견된 그림 2·3·5·6·8쪽은 내장 image_gen 도구로 직접 보정했다. 원본, 보정 지시, 수정 파일과 PDF 검증 기록은 `docs/acceptance/2026-09-06-reader-book/`에 분리 보관했다. 따라서 이 개인용 PDF의 완성도를 앱의 무인 자동 생성 품질 통과 근거로 사용하지 않는다. 원본 C1/C4 보류 판정은 유지하며, 보강 후 원본만 사용하는 15편 검증은 `2026-09-06-quality-matrix-sol-v2/`에서 별도로 진행한다.

기준일 2026-09-06. 기술 경로 통과와 콘텐츠 품질 판정을 구별한다. 앞선 8권은 가상 캐릭터·합성 이야기이며, 최근 1권은 **보호자 제공 이름**과 가상 외모·이야기를 사용했다. 실제 아동 사진은 사용하지 않았다. 최근 표본을 개인정보 없는 합성 표본으로 표시하지 않으며, 이름 원문은 이 문서에 기록하지 않는다. 현재 **공개 출시 품질 통과 판정은 보류**다.

자동 검사 최신 결과는 API **1,227 통과·14 건너뜀·커버리지 74.21%**, Flutter **359 통과·커버리지 49.66%**다. 진행 중인 등장인물 고정 보강의 집중 검증은 기존 전체 API 스냅샷과 구분한다. 자동 검사는 실제 그림 품질 판정을 대신하지 않는다. [현재 출시 상태](LAUNCH_STATUS.md), [자동 검사 증거](RELEASE_PREPARATION.md).

## 제공자의 역할과 선택 이력

[2026-08-22 결정 기록](REAL_KEYS_SETUP_GUIDE.md)에 Claude 선택 이유는 창작 문체·다국어, 특히 한국어·아동 안전 품질에 대한 기대라고 적혀 있다. GPT보다 저렴해서 선택했다는 기록은 확인하지 못했다. 이는 당시 판단 기록이며 두 모델의 실측 비교 증거는 아니다.

Gemini는 저장 서비스가 아니라 **사진을 참고한 캐릭터 및 삽화 생성 모델**이다. 현재 얼굴 참조 입력 경로가 Gemini 이미지 어댑터에 구현되어 있다. 원본 사진·완성 삽화·PDF는 별도 비공개 **S3 호환 저장소**가 보관하고, 이번 격리 검증에서는 MinIO를 사용했다. Google AI Studio의 결제 연결 자체가 Cloud Storage 버킷 연결을 의미하지 않는다.

2026-09-06 사용자는 GPT/Anthropic 중 가격보다 품질을 우선하도록 위임했다. 같은 제품 프롬프트·합성 캐릭터·3개 연령·동일한 4쪽 이야기 6과제로 4모델의 텍스트 비교를 완료했다. 형식·문자 무결성과 연령·서사·한국어·안전을 검토해 Sol을 선택했고, 이후 실제 전체 책 경로도 완료했다. `scripts/compare_story_models.py`는 모델당 과제별 1회·총6회까지만 허용하며 이미지·자동 재시도·설정 변경을 수행하지 않는다. 비교와 로컬 적용은 완료됐지만 전체 그림 품질은 별도 보류다.

## 발견 후 적용한 보완

- Gemini에 요청 비율을 전달하고, 부정 프롬프트와 빈 간판·책 표지 규칙을 적용했다.
- 사진 참조가 없는 합성 캐릭터 책은 해당 책의 표지 이미지를 페이지 참조로 사용한다. 실제 사용자 사진 참조가 있으면 우선권을 유지한다.
- 조연의 의상·연령·외형을 반복 고정하고, 미래 장면의 사물이나 상태가 앞쪽에 나오지 않도록 장면 지시를 보완했다. 프롬프트만으로 무오류를 보증하지 않으며 실제 표본의 위반은 그대로 기록한다.
- 한글 JSON 이스케이프를 줄여 불필요한 입력 토큰을 줄였고, 페이지 수에 맞춰 응답 한도를 늘렸다. 기본 LLM 대기 시간은90초다.
- DTO 길이 제한을 생성 프롬프트에 명시하고, 스키마 오류 진단에서는 정적인 필드 경로·오류 유형만 남긴다. 원문·아이 정보·비밀키가 포함된 파싱 오류를 로그에 쓰지 않는다.
- 텍스트 캐릭터는 AI 응답과 최종 반환 DTO를 **저장 전에** 검증한다. 동물의 미착용 의복은 명시적인 ‘없음’으로 처리하며, 누락·초과·잘못된 구조는 제한된 재시도 후 실패한다.
- 모든 모델에 공통으로 [문자·언어 무결성 검사](STORY_TEXT_INTEGRITY.md)를 적용한다. 실제 실패 표본의 깨진 글자와 외국어 혼입을 추가 AI 호출 없이 다시 차단했으며, 이야기가 통과하기 전에는 이미지 비용을 발생시키지 않는다. 의미·사건 순서·그림과의 일치는 별도 검토 대상이다.
- 최신 GPT에는 stateless Responses API와 명시적인 출력·추론 한도를 적용했다. 완료되지 않은 응답·거절·빈 텍스트를 정상 동화로 저장하지 않는다. 호출 API에서 `store:false`를 사용하며 파일 업로드·검색·외부 도구 권한은 사용하지 않는다.
- PDF는 세로 그림과 불투명 본문 영역을 분리하고, 긴 글을 이어지는 페이지에 보존한다. 완성10쪽과 긴 본문 표본의 전 페이지를 렌더링하고 텍스트 보존을 확인했다.

## 첫 Anthropic 확대 검증의 품질 기록

당시 15편 계획 중 3편 생성·검토 완료, 1편 캐릭터 생성 실패, 11편 미실행이다. 실패 표본을 삭제하거나 점수를 높여 다시 합산하지 않는다. 완성3편의 C1–C5 점수는 각각 `2/2/2/1/2`, `2/1/2/2/0`, `2/1/2/2/2`다. S1 위반은 해당3편에서0건이나, 15편 전체 통과나 실제 아동 얼굴 보존 통과를 의미하지 않는다.
