## 보존한 자동 생성 품질 기준선 — REDESIGN_REQUIRED

새 Sol/Pro 15권 자동 생성의 최종 판정은 **재설계 필요**입니다. 본문 **60쪽·원본 그림 75장**을 모두 검토했으며, C1의 2점 합격률 **53.3333%**가 사전 중단 기준 **60% 미만**에 해당합니다. 현재 출시 GO가 아니며 **유료 생성은 모두 중지**했습니다. [최종 품질 집계](acceptance/2026-09-06-quality-matrix-sol-v2/quality-summary.json).

이후 **전체 그림 검사·부분 재생성·재검사**를 구현하고 실제 저장 그림의 교정도 검증했습니다. [그림 품질 검사](ILLUSTRATION_QUALITY_GATE.md)에 근거가 있습니다. 새 독립 표본 전수 품질 GO는 아니며, 현재 내부 작업은 등록 전 디자인 보완·공동 테스트입니다. 이미 완료한 계정·결제의 재승인을 기다리지 않습니다.

이전 실패 기록은 보존합니다. 첫 Sol/Pro 행렬은 초기 2권 ImagePrompts 길이 초과, 이미지 **0회**, 텍스트 추정 **$0.3801**, 나머지 **13편 미실행**으로 종료됐습니다. 네이티브 ImagePrompts와 참조·등장인물 연결 보강 이후 별도 새 15권을 실행한 것이 위 최종 기준선입니다.

보호자 제공 이름 8쪽 원본의 기술 결과는 **228.23초 / LLM 6회 / 이미지 9회**, 텍스트 **$0.263580**·이미지 **$1.266672** 추정 비용입니다. 자동 원본은 **C1=0 / C2=2 / C3=2 / C4=1 / C5=2, S1 위반 0**으로 보류했고, 그림을 별도 편집한 개인 읽기용 최종 PDF는 원문과 10페이지 렌더 검증을 완료했습니다. 그 편집본은 새 15권 품질 집계에서 제외합니다.

운영 서버·공개 HTTPS·비공개 S3·외부 백업·AI 이용 조건·서비스 법적 고지·실기기 검증은 남아 있습니다. Apple 약관과 기존 개인 계정 정보 확인은 완료됐고, 스토어 등록은 공동 최종 검토 이후로 두었습니다.

[DEPLOYMENT.md](DEPLOYMENT.md)와 [BACKUP_RESTORE.md](BACKUP_RESTORE.md)의 기존 절차를 사용합니다. 현재 프로젝트에서 접근 가능한 운영 대상은 확인되지 않았습니다. 로컬 복원 리허설 통과는 운영 백업이 이미 보관되고 있다는 뜻이 아닙니다.

운영 설정의 초기 베타 범위는 다음과 같습니다.

```dotenv
PURCHASES_ENABLED=false
AUDIO_FEATURE_ENABLED=false
POD_ORDERING_ENABLED=false
```

서버·공개 HTTPS 주소·저장소가 준비되면 구현자가 운영 설정 점검과 SHA 이미지 배포를 이어갑니다. 상세 값과 명령은 배포 문서를 정본으로 사용합니다.
