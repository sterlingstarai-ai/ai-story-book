2026-09-07. 사용자가 전달한 두 독립 AI의 E2E 보고서를 현재 작업 트리와 대조했다. 첫 AI의 기존 수정은 보존하며 검토했고, 두 번째 보고서의 미수정 결함과 첫 보고서의 잔여 결함을 보완했다. 커밋·푸시·운영 배포·스토어 등록은 이 작업에 포함하지 않았다.

## 기각하거나 범위를 바로잡은 주장

- **전역 일일 비용 예산 20을 즉시 높이는 조치:** 기각. 현재 제한 베타의 비용 보호 장치다. 계정별 책 한도의 잘못된 집계는 고치되, 재생성 등의 유료 호출을 전역 계량에서 빼거나 수치만 높이지 않는다. 공개 서비스 규모에 맞춘 상향은 운영 예산·수용 인원을 함께 정할 때 다룬다.
- **리텔 경로 전체가 프로필을 상속하지 않는다는 주장:** 부분 기각. 검수를 거쳐 출판하는 리텔은 이미 새 책과 작업 양쪽에 프로필을 상속하고 있었다. 일반 경로의 작업과 요청 범위 검사만 실제로 부족했다.
- **큰 글씨에서 본문 높이가 화면보다 큰 것 자체가 잘림이라는 해석:** 기각. 본문은 스크롤하도록 설계되어 있다. 마지막 줄이 읽히는지와 하단 버튼이 가리는지를 기하 검사로 확인한다.
- **마지막 캐릭터 카드가 플로팅 버튼에 가려진다는 주장:** 현 버전에서 재현되지 않아 기각. 기존 하단 여백 112px에서 320×480·1.6배 글씨로 끝까지 스크롤하면 카드 하단이 버튼 위에 놓인다.
- **일반 오류를 반드시 서버 원문으로 보여야 한다는 M29 해석:** 기각. 일반 실패의 서버 안전 문구는 한국어 고정이어서 영어·일본어 화면에 부적합하다. 안전 관련 사용자 설명 보존과 일반 오류 현지화는 구분한다.
- **PDF 내보내기가 검증 완료라는 확대 해석:** 기각. 두 보고서 모두 실제로 확인한 것은 무료 베타의 402 기능 제한과 안내다. 실제 PDF 내보내기 성공으로 계산하지 않는다.
- **실제 책 두 권 성공을 전반적인 합격률로 확대:** 기각. 서로 다른 신규 자동 표본 두 건이라는 근거로만 인정한다. 기존 수동 교정판과 과거 실패 결과는 별개로 보존한다.

## 제공자 설정 결정

사진 캐릭터 기능의 현재 구현과 두 실제 성공 표본에 맞춰 **로컬 개발 실행은 OpenAI 글·검수 + GPT Image 2 그림**으로 정리했다. 기존의 서로 다른 제공자 키를 혼용하지 않도록 분석·이미지 키를 기존 전용 OpenAI 키에 연결했다. 원래 Gemini 설정은 비공개 로컬 백업에 보관했다. API 키를 새로 발급하거나 추가 결제하지 않았다.

원래 `.env`는 사진 기능이 꺼진 Gemini 이미지 구성으로, 그 구성 자체가 OpenAI 엔드포인트를 호출하는 것은 아니다. 보고서의 401은 제공자만 OpenAI로 바꾸고 Gemini 이미지 키를 그대로 둔 시험 구성에서 발생했다. 따라서 제공자 장애로 분류하지 않고 **로컬 시험 설정의 불일치**로 판정했다. 현재 로컬 설정 검사와 사진 준비 함수는 외부 호출 없이 통과했다.

이 설정은 사용자가 승인한 개인 사진 시험의 연장이다. 운영 설정은 변경하지 않았으며, 제공자의 데이터 처리 조건이나 ZDR 승인을 받은 것으로 표시하지 않는다. Google과 OpenAI 이미지의 동일 조건 비교 우위가 입증된 것은 아니다.
